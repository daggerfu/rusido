## Замечания по NLP-интеграции (pymorphy3)

- [x] **Синкретизм падежей снят контекстным выбором гипотезы pymorphy3** (D-024): приоритет леммы из лексикона → контекстной гипотезы падежа (предлог, SVO-объект, подлежащее) → частотной оценки. «книги» → «книги» (им. мн.) / «книгиу» (вин. мн. после глагола), «дверь» → «двер» / «дверу». Управление Rusido (§8.6) для предлогов перекрывает русский падеж: «у книги» → «у книге». Дополнено 2026-11-17: предикат «нет» управляет родительным (§8.4, «У мне нет книго»), дательные предлоги требуют косвенной формы местоимения (§5.2, «у них» → «у ним»); регрессионные тесты в `test_translator.py`. Дополнено 2026-11-17: непереходные глаголы (`tran`/`intr` из pymorphy3) больше не порождают винительный объект (D-026, «я иду дом» → «я идем дом»). Остаток: частотный словарь для редкой омонимии.
- [x] **Будущее связки «будет»**: `будти` получило две функции — вспомогательную (`будет читати`) и связочную (`Он будет студент`); личная форма самостоятельна, русский падеж именного сказуемого не переносится, обладание согласуется с объектом по числу (`будет`/`будени`), `ест` инвариантно (D-025, §7.4/§8.3).
- [x] pymorphy3 зафиксирован в зависимостях `pyproject.toml` (минимальные версии не ограничены — стоит добавить нижние границы).
- [x] Валидатор не использует NLP — зафиксировано решением D-014: контекст русского предложения обрабатывает только переводчик, проверка Русидо остаётся независимой от внешних моделей.
