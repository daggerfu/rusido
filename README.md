# 1. ОБЩАЯ КОНЦЕПЦИЯ РУСИДО

## 1.1. Название

**Русидо** — искусственный язык, основанный на русской лексической базе и регулярной грамматической системе.

Название образовано:

**Рус + идо**

где:

* **Рус** — русский язык, русская лексика;
* **-идо** — идея упорядочивания и создания вспомогательного языка.

---

# 1.2. Цель языка

Русидо создаётся не как замена русского языка, а как его рационализированная форма.

Главная идея:

> Сохранить узнаваемость русского языка, но устранить исключения, нерегулярность и сложность грамматики.

Основные принципы:

1. **Одно правило → один результат.**
2. **Нет грамматических исключений.**
3. **Слова сохраняют русские корни.**
4. **Грамматика полностью регулярна.**
5. **Все изменения выражаются отдельными морфемами.**

---

# 1.3. Тип языка

Русидо является:

* агглютинативным;
* синтетическим в словоизменении;
* аналитическим в сложных конструкциях.

Пример:

Русский:

> красивыми домами

Русидо:

> красивий домиами

Структура:

```
дом + и (множественное число) + а (родительный падеж)
```

Каждая морфема имеет одно значение.

# 2. АЛФАВИТ

## 2.1. Полный алфавит Русидо

Русидо использует 29 букв:

```
А Б В Г Д Е Ж З И Й К Л М Н О П Р С Т У Ф Х Ц Ч Ш Щ Ь Ю Я
```

Строчная форма:

```
а б в г д е ж з и й к л м н о п р с т у ф х ц ч ш щ ь ю я
```

---

# 2.2. Отсутствующие буквы

В Русидо отсутствуют:

| Русская буква | Замена |
| ------------- | ------ |
| ё             | е      |
| ы             | и      |
| э             | е      |
| ъ             | ь      |

Примеры:

Русский:

```
ёлка
чёрный
это
объект
```

Русидо:

```
елка
черний
ето
обьект
```

# 3. ФОНЕТИКА

# 3.1. Гласные

В Русидо семь гласных:

```
а е и о у ю я
```

---

## Произношение:

| Буква | Значение               |
| ----- | ---------------------- |
| а     | [а]                    |
| о     | [о]                    |
| у     | [у]                    |
| и     | [и]                    |
| е     | [э] / [йэ]             |
| я     | [а] с мягкостью / [йа] |
| ю     | [у] с мягкостью / [йу] |

---

# 3.2. Отсутствие редукции

В русском:

```
вода → вада
молоко → малако
```

В Русидо:

```
вода
молоко
```

Каждая буква произносится так, как написана.

---

# 3.3. Согласные

Согласные:

```
б в г д ж з й к л м н п р с т ф х ц ч ш щ
```

---

# 3.4. Мягкость согласных

Согласные становятся мягкими перед:

```
е
и
я
ю
ь
```

Примеры:

```
люди
земя
тихий
день
```

---

# 3.5. Мягкий знак

## ь — единственный знак мягкости

Функции:

### 1. Обозначение мягкости:

```
конь
дверь
письмо
```

### 2. Замена русского ъ:

Русский:

```
объект
подъезд
съезд
```

Русидо:

```
обьект
подьезд
сьезд
```

Буква **ъ полностью запрещена**.

# 4. УДАРЕНИЕ

## 4.1. Основное правило

Ударение всегда падает на предпоследний слог.

Примеры:

```
кни́га
маши́на
работа́
```

В Русидо:

```
книга
машина
работа
```

ударение:

```
кни-га
ма-ши-на
ра-бо-та
```

---

## 4.2. При словоизменении

Ударение не зависит от формы слова.

Русский:

```
рука́
ру́ки
рука́ми
```

Русидо:

```
рука
руки
руками
```

# 6. СУЩЕСТВИТЕЛЬНЫЕ

# 6.1. Общая структура

Существительное строится:

```
КОРЕНЬ + ЧИСЛО + ПАДЕЖ
```

Пример:

```

```

```
стол = основа
```

# 6.2. Основа существительного

Основа:

русский корень без окончания.

Примеры:

| Русский | Основа Русидо |
| ------- | ------------- |
| стол    | стол          |
| вода    | вод           |

| армия   | арми          |

---

# 6.3. Грамматический род

В Русидо нет обязательного рода.

## Неодушевлённые существительные:

Рода нет.

Пример:

```

```

---

## Одушевлённые:

Используются специальные суффиксы пола.

Мужской:

```

```

Женский:

```
-ица
```

Пример:

```

```

---

# 6.4. Число

Русидо имеет три числа:

| Число         | Окончание |
| ------------- | --------- |
| Единственное  | ∅         |
| Двойственное  | -а        |
| Множественное | -и        |

---

## Единственное число

Один предмет:

```
стол
книга
дом
```

---

## Двойственное число

Два предмета:

```
стола
книгаа
дома
```

Используется только для количества два.

---

## Множественное число

Три и больше:

```
столи
книги
доми
```

---

# 9. ПРИЛАГАТЕЛЬНЫЕ

## 9.1. Общий принцип

В Русидо прилагательные являются **неизменяемыми словами**.

Они не имеют:

* рода;
* числа;
* падежа.

Форма всегда одна.

Структура:

```
ОСНОВА + -ий
```

---

## 9.2. Образование прилагательных

Примеры:

Русский:

* красивый
* новый
* большой
* синий

Русидо:

```
красивий
новий
болший
синий
```

---

## 9.3. Положение в предложении

Прилагательное всегда стоит **перед существительным**.

Формула:

```
ПРИЛАГАТЕЛЬНОЕ + СУЩЕСТВИТЕЛЬНОЕ
```

Примеры:

Русский:

> красивый дом

Русидо:

> красивий дом

---

Русский:

> новые книги

Русидо:

> новий книги

---

Русский:

> в большом доме

Русидо:

> в болший дому

Прилагательное не изменяется.

---

# 9.4. Степени сравнения

## Сравнительная степень

Образуется словом:

```
более + прилагательное
```

Примеры:

```
более красивий
более быстрый
более умний
```

---

## Превосходная степень

Образуется:

```
самий + прилагательное
```

Примеры:

```
самий красивий
самий большой
самий важний
```

---

# 9.5. Краткие формы

В Русидо отсутствуют.

Русский:

> дом красив

Русидо:

> дом ест красивий

или:

> дом красивий

# 14. ОБЩИЙ ПРИНЦИП ГЛАГОЛА

Глагольная система Русидо полностью регулярна.

Главный принцип:

> Один глагол — одна модель спряжения.

В Русидо отсутствуют:

* первое и второе спряжение;
* чередования корней;
* исключительные глаголы;
* неправильные формы;
* видовые пары как обязательная категория.

---

# 14.1. Структура глагола

Формула:

```
ОСНОВА + ГРАММАТИЧЕСКИЙ АФФИКС
```

Инфинитив:

```
ОСНОВА + ти
```

Примеры:

| Русский  | Русидо   |
| -------- | -------- |
| читать   | читати   |
| делать   | делати   |
| любить   | любити   |
| идти     | ити      |
| говорить | говорити |

---

# 14.2. Основа глагола

Основа получается удалением окончания:

```
-ти
```

Примеры:

| Инфинитив | Основа |
| --------- | ------ |
| чита-ти   | чита   |
| дела-ти   | дела   |
| люби-ти   | люби   |
| говори-ти | говори |

Настоящее время:

# 27. ОБЩИЙ ПРИНЦИП СИНТАКСИСА

Русидо сохраняет русскую логику построения фраз, но вводит более строгий порядок слов.

Главный принцип:

> Грамматические отношения выражаются не свободным порядком слов, а фиксированной структурой и морфемами.

Русидо использует преимущественно:

```id="8qj8ry"
SVO
```

где:

* **S (Subject)** — подлежащее;
* **V (Verb)** — сказуемое;
* **O (Object)** — дополнение.

---

Пример:

Русский:

> Я читаю книгу.

Русидо:

> Я читам книгуу.

Структура:

```id="9rmh4w"
Я | читам | книгуу
S | V | O
```

---

# 28. ПОРЯДОК СЛОВ

## 28.1. Базовый порядок

Основная структура:

```id="eqt3a1"
Подлежащее + Сказуемое + Дополнение
```

Примеры:

> Брат читат книгу.

> Собака видит кота.

> Учитель объясняет урок.

---

# 28.2. Допустимое изменение порядка слов

Так как Русидо сохраняет падежи, порядок слов может изменяться для выделения смысла.

Нейтрально:

> Я читам книгуу.

Выделение объекта:

> Книгуу я читам.

Выделение действия:

> Читам я книгуу.

Однако стандартный порядок:

```id="sk5nqb"
SVO
```

предпочтителен.

---

# 35. ПРЕДЛОГИ

Предлоги в Русидо:

* не изменяются;
* стоят перед существительным;
* требуют определённого падежа.

---

# 35.1. Пространственные предлоги

## в

Значение:

* нахождение внутри;
* направление внутрь.

Примеры:

Статика:

> в дому

Направление:

> в дом

---

## на

Значение:

* поверхность;
* направление на поверхность.

Примеры:

> на столе

> на столу

---

## у

Значение:

* владение;
* нахождение рядом.

Примеры:

> у брата

> у нему

---

## к

Направление к объекту.

Пример:

> Я иду к брате.

---

## из

Источник движения.

Пример:

> Я иду из дому.

---

## от

Удаление от объекта.

Пример:

> Я пришел от друга.

---

# 35.2. Социальные и логические предлоги

| Предлог | Значение          | Пример             |
| ------- | ----------------- | ------------------ |
| с       | вместе с          | с брат             |
| без     | отсутствие        | без книги          |
| для     | цель              | для друга          |
| о       | тема              | о городе           |
| од      | источник действия | написано од автора |

# 43. ОБЩИЙ ПРИНЦИП СЛОВООБРАЗОВАНИЯ

Русидо использует ограниченную систему продуктивных морфем.

Главный принцип:

> Один аффикс имеет одно основное значение.

Новые слова создаются:

```

```

Пример:

```

```

где:

* учи — корень;
* -т — глагольная основа;
* -ник — человек, выполняющий действие.

| книгу   | книгуу |

Алгоритм:

```python
def noun_rusido(root, case, number):

    result = root

    if number=="plur":
        result += "и"

    if case=="acc":
        result += "у"

    elif case=="gen":
        result += "о"

    elif case=="dat":
        result += "е"

    return result
```

# 7. Синтаксическая перестройка

Например:

Русский:

> Я читаю новую книгу.

spaCy даст:

```
Я      nsubj
читаю  root
новую  amod
книгу  obj
```

Структура:

```
S V O
```

Русидо:

```
Я читам новий книгуу.
```

Генератор:

```python
def sentence_builder(tokens):

    subject=[]
    verb=[]
    object=[]

    for t in tokens:

        if t.dep_=="nsubj":
            subject.append(t.text)

        if t.pos_=="VERB":
            verb.append(t.text)

        if t.dep_=="obj":
            object.append(t.text)


    return (
        subject+
        verb+
        object
    )
```
