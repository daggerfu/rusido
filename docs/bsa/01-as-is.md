# AS-IS — текущее состояние РУСИДО Tools 0.1.0 (MVP)

Дата среза: 2026-11-17. Детали: `plan.md` §1, проблемы — `TODO.md`.

## 1. Продукт в одном абзаце

Python-пакет `rusido` для искусственного регулярного языка Русидо (русская лексика +
агглютинативная грамматика без исключений). Два ядра: переводчик (русский → Русидо,
pymorphy3 + эвристики) и валидатор (уровни: орфография → лексика → морфология →
синтаксис, стабильные коды R001—R018). Общий лексикон (621 запись) и общая морфология.

## 2. Что реализовано (сводка)

| Область | Состояние |
|---|---|
| Алфавит/нормализация | Готово: 29 букв, замены ё/ы/э/ъ, удвоенные согласные (Rusido.md §2) |
| Морфология | Готово: существительные ROOT+NUMBER+CASE, глаголы (спряжение, эпентеза, алломорфы §7.1.1), прилагательные `-ий`, числительные 0–9999 + порядковые `-им`, местоимения §5 |
| Лексикон | Готово: 621 запись (`dictionary.py` + `bootstrap.py` + `data/lexicon/*.json`), JSON + SQLite, служебные формы §2.2 (D-004) |
| Валидатор | Базово+: реестр R001—R018 (D-019), внешние токены §1.1/§6.7, позиции line/column/start/end, все примеры Rusido.md валидируются |
| Переводчик | Базово + NLP (pymorphy3), откат на эвристики (`use_nlp=False`), `RU_TO_LEMMA_OVERRIDES`, warnings/confidence |
| CLI | Базово: `translate`, `validate`, `corpus add/search/stats`, `dictionary list/export/import` |
| Грамматика как данные | YAML `data/grammar/grammar.yaml` + `GrammarProfile`, версии грамматики |
| Инфраструктура | `pyproject.toml` + entry point `rusido`; 213 pytest-тестов, все зелёные |
| Спецификация | Противоречия закрыты (ревизия по 20 пунктам), решения D-001…D-023 |

## 3. Ограничения и боли (pain points)

1. **Синкретизм падежей pymorphy3** — «книги» разбирается первой гипотезой как род. ед.
   («книго»), «столы» как вин. мн.; контекст предложения не учитывается (TODO, NLP-раздел).
2. **Смешанное поведение связки** — NLP разбирает «будет» как future «быть», эвристика
   оставляет неизменным; в спецификации не зафиксировано (TODO).
3. **Reserved-коды** — R002–R004, R009–R014, R016 определены условиями, но не реализованы
   (нет проверки управления предлогов, подсветки фрагмента, score).
4. **Нет CI** — pytest запускается вручную; нет нижних границ версий pymorphy3 (TODO).
5. **Evaluation не начат** — нет корпуса Русидо, метрик BLEU, частотного анализа.
6. **Bootstrap-качество основ** — основы ~500 слов выведены эвристикой и не вычитаны
   руками (`bootstrap.py`, README §4.5); заимствования и имена покрыты только оболочкой
   внешних токенов.
7. **spaCy-режим отсутствует** — критерий выхода из MVP №4 открыт.
8. **Слепые зоны переводчика** — «она/оно» не сводятся к `он` (§5.1), часть служебных
   и модальных глаголов пока не переводится.

## 4. Контекстная диаграмма (текстово)

```
                 ┌─────────────────── rusido (пакет) ───────────────────┐
 русский текст → │ RusidoTranslator (pymorphy3 / эвристики)             │ → текст Русидо
 текст Русидо  → │ RusidoValidator (орфография→лексика→морфология→синт.)│ → отчёт R001—R018
 слово/текст   → │ RusidoAnalyzer, RusidoConfig, GrammarProfile (YAML)  │ → разбор / конфиг
 пользователь  → │ CLI rusido: translate | validate | corpus | dictionary│ → stdout/stderr, SQLite
                 └──────────────────────────────────────────────────────┘
        ↑ общие: Lexicon (621 запись, JSON+SQLite), rusido.morphology, normalizer
```

## 5. Ключевые нефункциональные характеристики (как есть)

- Python 3.11+, нулевые обязательные зависимости кроме pymorphy3 (опционален).
- Валидатор работает без внешних NLP-моделей (D-014) — детерминирован, проверяем.
- Лицензия/публикация: не определены (PyPI после стабилизации грамматики v1.0).
