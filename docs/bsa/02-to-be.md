# TO-BE — целевое состояние РУСИДО Tools

Вехи: **v0.2** (выход из MVP) → **v1.0** (стабильная грамматика и публикация).
Детали плана: `plan.md` §2–3; обоснование решений фиксируется в `docs/decisions.md`.

## 1. Целевая архитектура

```
русский текст ─┬─► переводчик ──► текст Русидо ──► валидатор ──► отчёт (score, позиции)
               │      ▲                                   ▲
               │   NLP-конвейер                     единая морфология
               │   (pymorphy3 → spaCy)             (rusido.morphology, GrammarProfile)
               │      │                                ▲
               │   контекстный разбор                  │
               │   (снятие синкретизма)            Lexicon (ручная вычитка основ)
               └──────────────────────────────────────────────┘
 CLI (полный набор команд README §8) │ evaluation/ (корпус, BLEU) │ PyPI-пакет
```

## 2. Веха v0.2 — выход из MVP

Критерии (plan.md §3) и их целевое состояние:

1. Противоречия спеки закрыты, решения в D-xxx — ✅ уже достигнуто (AS-IS §2).
2. Грамматика из YAML, `grammar_version` работает — ✅ уже достигнуто; добавить
   флаг `--grammar` в CLI.
3. Лексикон ≥ 500 записей — ✅ превышено (621); цель v0.2 — **ручная вычитка
   bootstrap-основ** (перенос в явный словарь, см. bootstrap.py docstring).
4. Переводчик в режиме normal без spaCy ✅ / со spaCy — **цель**: бэкенд
   `ru_core_news_sm` (синтаксис, снятие омонимии, выбор подлежащего/объекта),
   режимы strict / normal / best_effort с порогами уверенности.
5. Коды R001—R018: реализовать reserved (R002–R004, R009–R014, R016) или снять
   с документированными критериями; управление предлогов; `score` в отчёте;
   экспорт JSON.
6. Пакет ставится через pip, команда `rusido` — ✅ уже достигнуто.

Дополнительно в v0.2: CI (GitHub Actions: pytest на Python 3.11–3.13), нижние
границы pymorphy3, фиксация в спеке перевода связки «будет», «она/оно» → `он`.

## 3. Веха v1.0 — стабилизация

- Грамматика языка заморожена; новые решения только через `docs/decisions.md`.
- `evaluation/`: параллельный корпус русский ↔ Русидо, BLEU (NLTK), частотный анализ,
  регрессионные метрики качества перевода.
- Property-тесты морфологии (любая сгенерированная форма валидна).
- ruff + mypy в CI; документация `docs/`; `examples/`.
- Публикация на PyPI (`rusido-tools`).
