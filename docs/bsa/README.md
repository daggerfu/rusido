# BSA-комплект РУСИДО Tools

Полный набор артефактов бизнес-системного анализа: AS-IS → TO-BE → User Stories → Use Cases.
Дата составления: 2026-11-17. Версия продукта: 0.1.0 (MVP).

Эти документы — «витрина»: они сводят и маркируют информацию, детали которой живут в
рабочих документах проекта. Правило поддержки: обновлять на вехах (v0.2, v1.0),
внутри вехи актуальны `plan.md` и `TODO.md`.

## Состав

| Файл | Артефакт | Роль |
|---|---|---|
| `01-as-is.md` | AS-IS | Текущее состояние MVP: что есть, ограничения, боли |
| `02-to-be.md` | TO-BE | Целевое состояние v0.2 / v1.0 и критерии перехода |
| `03-user-stories.md` | User Stories | Сценарии ценности от актёров, критерии приёмки |
| `04-use-cases.md` | Use Cases | Формальные варианты использования с потоками |

## Источники (детали по ссылкам)

- `README.md` — архитектурная концепция (§8 CLI, §9 коды ошибок, §11 сквозной тест, §13 открытые вопросы, §14 дорожная карта, §15 критерий лексикона).
- `Rusido.md` — спецификация языка Русидо (алфавит, морфология, синтаксис).
- `proposal.md` — обоснование концепции.
- `plan.md` — рабочая дорожная карта (§1 сделано, §2 план, §3 критерии выхода из MVP).
- `TODO.md` — открытые проблемы и техдолг.
- `docs/decisions.md` — журнал решений D-001…D-023 (ADR-стиль).
