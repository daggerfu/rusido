# Руководство пользователя РУСИДО Tools

Это практическое руководство: от установки до перевода собственных текстов и
проверки Русидо. Подробности архитектуры — в `README.md`, правила языка — в
`Rusido.md`, обоснования решений — в `docs/decisions.md`.

---

## 1. Что такое Русидо (за 2 минуты)

Русидо — регулярный русский язык: русские корни + агглютинативная грамматика
без исключений, рода и сложного согласования.

```
Я читаю новую книгу.  →  Я читам новий книгу.
```

Ключевое для понимания вывода:

- Алфавит 29 букв: нет `ё ы э ъ` (замены `ё→е, ы→и, э→е, ъ→ь`), удвоенные
  согласные сокращаются (`класс → клас`).
- Существительное: `ОСНОВА + число + падеж`: мн. ч. `-и`, вин. `-у`,
  род. `-о`, дат. `-е` → `книг` → `книгу`, `книги`, `книгио`.
- Глагол: основа + окончание лица (`чита- + т = читат`); у основ на согласный
  вставляется `е` (`ид + е + м = идем`, прошедшее `идел`).
- Прилагательные неизменяемые: `нов + ий = новий`, всегда перед существительным.
- Порядок слов SVO.

## 2. Установка

Требуется Python 3.11+.

```bash
git clone <репозиторий> && cd rusido-tools
pip install -e .
```

Переводчик использует pymorphy3 (ставится автоматически). Без него
переводчик работает в режиме эвристик (`--no-nlp`), качество ниже.

Проверка установки:

```bash
rusido --help
echo "Я читаю книгу." | rusido translate
# → Я читам книгу.
```

Запуск без установки (из корня репозитория): `PYTHONPATH=src python3 -m rusido.cli …`

## 3. Перевод: rusido translate

### Из файла в файл

```bash
rusido translate input.txt -o output.rus
```

### Из stdin в stdout

```bash
cat input.txt | rusido translate
rusido translate "Мы изучаем русский язык."
```

### Без NLP (только эвристики MVP)

```bash
rusido translate --no-nlp input.txt
# «читаю» останется непереведённым: эвристики не разбирают формы, только леммы
```

### Что нужно знать о качестве

- Формы настоящего/прошедшего/будущего времени переводятся через pymorphy3.
- Неизвестные лексикону слова **не переводятся**, а только орфографически
  нормализуются (`ещё → еше`… нет: `ешо` — см. ниже); перевод печатает
  предупреждение в stderr:

  ```bash
  echo "Я вижу квартиру." | rusido translate
  # → Я вижу квартиру.
  # stderr: rusido: предупреждение: неизвестное слово: вижу
  ```

  (`вижу` нет в лексиконе — добавьте своё слово, см. §7.)
- Синкретизм падежей разрешается первой гипотезой анализатора: «книги» может
  уйти в родительный ед. ч. (`книго`) вместо именительного мн. ч. Это
  ограничение MVP; список известных проблем — в `TODO.md`.

## 4. Проверка: rusido validate

```bash
rusido validate text.rus              # отчёт в консоль, код выхода 0/1
rusido validate -i text.rus -o report.txt
cat text.rus | rusido validate -
rusido validate --strict text.rus     # плюс R007 без финальной пунктуации
```

Пример отчёта:

```
валиден: нет
предложений: 1
слов: 3
ошибок: 1
предупреждений: 0
[R005] 1:2 ошибка: неизвестное слово 'читаю' (вариант: читать)
```

Диагностики имеют стабильные коды (R001—R016, таблица в README §9): R005 —
неизвестное слово с предложением ближайшего словарного, R006 — запрещённая
буква, R001 — несогласованность глагола с субъектом, R015 — нарушение числа
после числительного и т.д.

Идеальный контур работы: перевели → сразу проверили результат.

```bash
rusido translate input.txt -o out.rus && rusido validate out.rus
```

## 5. Python API

```python
from rusido import RusidoTranslator, RusidoValidator

translator = RusidoTranslator()                 # NLP включён
result = translator.translate("Я читаю книгу.")
print(result.text)          # Я читам книгу.
print(result.confidence)    # 1.0
print(result.warnings)      # []  (для неизвестных слов — предупреждения)

validator = RusidoValidator()
report = validator.validate(result.text)
print(report.valid)         # True

# пакетный перевод (один анализатор на все тексты)
results = translator.translate_batch(["Я читаю.", "Они работани."])
```

Полезные опции:

```python
RusidoTranslator(use_nlp=False)          # без pymorphy3
RusidoValidator(strict=True)             # строгий режим

# своя версия грамматики (YAML, README §10)
from rusido.core.grammar import load_grammar
grammar = load_grammar("data/grammar/grammar.yaml")
t = RusidoTranslator(grammar=grammar)
v = RusidoValidator(grammar=grammar)
```

Разбор слова:

```python
from rusido import RusidoAnalyzer
for item in RusidoAnalyzer().analyze("столиу"):
    print(item.root, item.number, item.case)   # стол plural accusative
```

## 6. Корпус и словарь (SQLite)

Все данные живут в одном файле базы (по умолчанию `data/rusido.db`,
переопределяется флагом `--db`).

```bash
# добавить пару предложений (перевод автоматически проходит валидацию)
rusido corpus add --ru "Я читаю книгу." --rusido "Я читам книгу."

# поиск по корпусу (регистронезависимо, по обоим языкам)
rusido corpus search "читам"

# статистика
rusido corpus stats
# предложений: 12
# валидных: 11
# непроверенных: 0
# слов в словаре: 545

# словарь: заливка лексикона в базу и экспорт в JSON
rusido dictionary import
rusido dictionary export dictionary.json
```

Зачем это нужно: пары предложений накапливаются в корпусе и в перспективе
станут тестовыми данными и обучающей выборкой переводчика (README §4.6).

## 7. Как добавить своё слово

Лексикон хранит основы явно (простое удаление окончания не всегда работает:
`книга → книг`, `дверь → двер`). Быстрый путь — программно:

```python
from rusido import Lexicon, RusidoTranslator
from rusido.lexicon.dictionary import LexiconEntry, POS_NOUN

lexicon = Lexicon()
lexicon.add(LexiconEntry(
    lemma="квартира",          # русская лемма (будет нормализована)
    stem="квартир",            # целевая основа Русидо
    pos=POS_NOUN,
))
# или через JSON: отредактируйте экспорт из `rusido dictionary export`,
# загрузите Lexicon.from_json(...) и передайте в RusidoTranslator(lexicon=...)
# → translate("квартира") = "квартиро", translate("квартиру") = "квартиру"
```

Для постоянного добавления — допишите запись в `src/rusido/lexicon/dictionary.py`
(базовый список) и `bootstrap.py` (генерируемые), затем `rusido dictionary import`.

## 8. Типичные проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Слово не переводится, предупреждение «неизвестное слово» | нет в лексиконе (всего ~545 записей) | добавьте слово (§7) |
| «книги» → «книго» вместо «книги» | синкретизм им./род. — первая гипотеза pymorphy3 | ограничение MVP, см. TODO |
| «буду читать» → двойной вспомогательный | связка «буду» NLP трактует как будущее | ограничение MVP, см. TODO |
| `ModuleNotFoundError: pymorphy3` | не установлены словари | `pip install pymorphy3 pymorphy3-dicts-ru` |
| Команда `rusido` не находится | пакет не установлен | `pip install -e .` или `python3 -m rusido.cli` с PYTHONPATH=src |
| Ошибка «не могу прочитать файл» | путь/права | проверьте путь; вход = `-` или stdin |

## 9. Учебные примеры

```bash
# 1. Простое предложение
echo "Я читаю новую книгу." | rusido translate        # Я читам новий книгу.

# 2. Множественное число и родительный
echo "У мне нет книго." | rusido validate             # валиден: да

# 3. Глагол с основой на согласный
echo "Он идет в город." | rusido translate            # Он идет в город.
# («идет» переведён через NLP; падеж «город» зависит от разбора, см. ограничения)

# 4. Сквозной контур: перевод и проверка
echo "Ми читами книги." | rusido validate             # валиден: да

# 5. Ошибка с исправлением
echo "Я читаш книгу." | rusido validate
# [R001] … несогласованность … (вариант: читам)
```
