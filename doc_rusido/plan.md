## 3. Критерии вихода из MVP (следующий веха — v0.2)
1. Противоречия спецификации закрити, `docs/decisions.md` заведен.
2. Граматика загружается из YAML, `grammar_version` работат.
3. Лексикон ≥ 500 записей.
4. Переводчик работат в режиме normal без spaCy и в полном режиме с spaCy.
5. Все коди R001–R016 определени и реализовани с документированими критериями.
6. Пакету устанавливается через pip, CLI `rusido` доступен как команда.
