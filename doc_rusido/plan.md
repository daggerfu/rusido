## 2. Што будет сделам

### Етап 1. Evaluation и переводчик v1
- Снятие синкретизма падежей: базовие случаи реализовани (D-024 + «нет» + косвение
  местоимения); связка «будет» закрита D-025 (вспомогательная + связочная функции
  `будти`). Остается частотний словар для редкой омонимии.
- Перевод местоимений «он/он» → `он` (по §5.1); модальние и служебние глаголи.
- spaCy-бекенд (`ru_core_news_sm`): синтаксис, разрешение омонимии, вибор подлежащего/обьекто.
- Режими strict / normal / best_effort с количественими порогами уверености.

### Етап 2. Валидатор v1
- Управление предлогов (R002/R003/R013): `в доме` для направления, `из домо` для источника.
- Реализация зарезервированих кодов (R009—R014, R016) либо их снятие с публикацией критериев.
- `score` в отчете по определеной формуле; експорт JSON.
- Развитие проверок сложний предложенио (несколько подлежащих, придаточние §8.9).

### Етап 3. CLI и граматика как дам
- Полний CLI по README §8: `analyze`, `word`, `stats`, `config`, `version`; флаги `--mode`, `--level`, `--format json`, `--grammar`; Rich-вивод (опционально).
- Флаг `--grammar` для вибора YAML-профиля в CLI.
- Модуль `evaluation/`: корпус Русидо, BLEU, частотний анализ.
- Примери в `examples/`, документация `docs/`.

### Етап 4. Качество и сопровождение
- CI (GitHub Actions): pytest на 3.x, установка через pyproject.toml.
- Нижние граници версий pymorphy3 в зависимостях.
- Property-тести морфологии (все сгенерирование форми валидни).
- ruff, mypy; публикация на PyPI после стабилизации граматики v1.0.
