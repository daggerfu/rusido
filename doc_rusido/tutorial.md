# Руководство пользователя РУСИДО Tools

Етот практическое руководство: от установки до перевода собствених текстов и
проверки Русидо. Подробности архитектури — в `README.md`, правилиу язико — в
`Rusido.md`, обоснования решений — в `docs/decisions.md`.

---

## 1. Что такой Русидо (за 2 минуто)

Русидо — регулярний руский язику: руский корени + аглютинативная граматика
без исключений, рода и сложний согласования.

```
Я читам новий книгу.  →  Я читам новий книгу.
```

Ключевое для понимания вивода:

- Алфавит 29 букв: нет `е и е ь` (замени `е→е, и→и, е→е, ь→ь`), удвоение
  согласние сокращаются (`клас → клас`).
- Существительное: `ОСНОВА + числ + падеж`: мн. ч. `-и`, вин. `-у`,
  род. `-о`, дат. `-е` → `книгио` → `книгу`, `книго`, `книгио`.
- Глагол: основа + окончание лицо (`чита- + т = читат`); у основ на согласний
  вставляется `е` (`ид + е + м = идеми`, прошедшее `идел`).
- Прилагательние неизменяемие: `новий + ий = новий`, всегда перед существительним.
- Порядок словио SVO.

## 2. Установка

Требуется Python 3.11+.

```bash
git clone <репозиторий> && cd rusido-tools
pip install -e .
```

Переводчик использует pymorphy3 (ставится автоматически). Без он
переводчик работат в режиме евристик (`--no-nlp`), качество низкий.

Проверка установки:

```bash
rusido --help
echo "Я читам книгу." | rusido translate
# → Я читам книгу.
```

Запуск без установки (из корено репозитория): `PYTHONPATH=src python3 -m rusido.cli …`

## 3. Перевод: rusido translate

### Из файла в файл

```bash
rusido translate input.txt -o output.rus
```

### Из stdin в stdout

```bash
cat input.txt | rusido translate
rusido translate "Ми изучами руский язику."
```

### Без NLP (только евристики MVP)

```bash
rusido translate --no-nlp input.txt
# «читам» останется непереведеним: евристики не разбирают форми, только леми
```

### Что нужний знати о качестве

- Форми настоящего/прошедшего/будущего времо переводятся через pymorphy3.
- Неизвестний лексикону слово **не переводятся**, а только орфографически
  нормализуются (`еще → еше`… нет: `ешо` — смотрем. низкий); перевод печатает
  предупреждение в stderr:

  ```bash
  echo "Я видем квартиру." | rusido translate
  # → Я видем квартиру.
  # stderr: rusido: предупреждение: неизвестний слов: видем
  ```

  (`видем` нет в лексиконе — добавьте свое слов, смотрем. §7.)
- Синкретизм падежей разрешается первий гипотезой анализатора: «книго» может
  уйти в родительний ед. ч. (`книго`) вместо именительного мн. ч. Етот
  ограничение MVP; список известий проблем — в `TODO.md`.

## 4. Проверка: rusido validate

```bash
rusido validate text.rus              # отчет в консоль, код вихода 0/1
rusido validate -i text.rus -o report.txt
cat text.rus | rusido validate -
rusido validate --strict text.rus     # плюс R007 без финальной пунктуации
```

Пример отчета:

```
валиден: нет
предложенио: 1
словио: 3
ошибок: 1
предупреждений: 0
[R005] 1:2 ошибка: неизвестний слов 'читам' (вариант: читати)
```

Диагностики имеют стабильние коди (R001—R016, таблица в README §9): R005 —
неизвестний слов с предложене ближайшего словарного, R006 — запрещеная
буква, R001 — несогласованость глагола с субьектом, R015 — нарушение число
после числительного и т.д.

Идеальний контур работо: перевели → сразу проверили результат.

```bash
rusido translate input.txt -o out.rus && rusido validate out.rus
```

## 5. Python API

```python
from rusido import RusidoTranslator, RusidoValidator

translator = RusidoTranslator()                 # NLP включен
result = translator.translate("Я читам книгу.")
print(result.text)          # Я читам книгу.
print(result.confidence)    # 1.0
print(result.warnings)      # []  (для неизвестний словио — предупреждения)

validator = RusidoValidator()
report = validator.validate(result.text)
print(report.valid)         # True

# пакетний перевод (один анализатор на все тексти)
results = translator.translate_batch(["Я читам.", "Они работани."])
```

Полезние опции:

```python
RusidoTranslator(use_nlp=False)          # без pymorphy3
RusidoValidator(strict=True)             # строгий режим

# своя версия граматики (YAML, README §10)
from rusido.core.grammar import load_grammar
grammar = load_grammar("data/grammar/grammar.yaml")
t = RusidoTranslator(grammar=grammar)
v = RusidoValidator(grammar=grammar)
```

Разбор слово:

```python
from rusido import RusidoAnalyzer
for item in RusidoAnalyzer().analyze("столиу"):
    print(item.root, item.number, item.case)   # столу plural accusative
```

## 6. Корпус и словар (SQLite)

Все дание жини в одном файле бази (по умолчанию `data/rusido.db`,
переопределяется флагом `--db`).

```bash
# добавить пару предложенио (перевод автоматически проходит валидацию)
rusido corpus add --ru "Я читам книгу." --rusido "Я читам книгу."

# поиск по корпусу (регистронезависимо, по обоим язикие)
rusido corpus search "читам"

# статистика
rusido corpus stats
# предложенио: 12
# валидних: 11
# непроверених: 0
# словио в словаре: 545

# словар: заливка лексикона в базу и експорт в JSON
rusido dictionary import
rusido dictionary export dictionary.json
```

Зачем етот нужний: пари предложенио накапливаются в корпусе и в перспективе
станут тестовими даними и обучающей виборкой переводчика (README §4.6).

## 7. Как добавить свое слов

Лексикон хранит основи явно (простий удаление окончания не всегда работат:
`книг → книгио`, `дверу → двер`). Бистрий пут — програмно:

```python
from rusido import Lexicon, RusidoTranslator
from rusido.lexicon.dictionary import LexiconEntry, POS_NOUN

lexicon = Lexicon()
lexicon.add(LexiconEntry(
    lemma="квартира",          # руский лема (будет будти нормализована)
    stem="квартир",            # целевая основа Русидо
    pos=POS_NOUN,
))
# или через JSON: отредактируйте експорт из `rusido dictionary export`,
# загрузите Lexicon.from_json(...) и передайте в RusidoTranslator(lexicon=...)
# → translate("квартира") = "квартиро", translate("квартиру") = "квартиру"
```

Для постояного добавления — допишите запись в `src/rusido/lexicon/dictionary.py`
(базовий список) и `bootstrap.py` (генерируемие), затем `rusido dictionary import`.

## 8. Типичние проблеми

| Симптом | Причина | Решение |
|---|---|---|
| Слов не переводится, предупреждение «неизвестний слов» | нет в лексиконе (всего ~545 записей) | добавьте слов (§7) |
| «книго» → «книго» вместо «книго» | синкретизм они./род. — первий гипотеза pymorphy3 | ограничение MVP, смотрем. TODO |
| «будем будти читати» → двойной вспомогательний | связка «будем будти» NLP трактует как будущее | ограничение MVP, смотрем. TODO |
| `ModuleNotFoundError: pymorphy3` | не установлени словариу | `pip install pymorphy3 pymorphy3-dicts-ru` |
| Команда `rusido` не находится | пакету не установлен | `pip install -e .` или `python3 -m rusido.cli` с PYTHONPATH=src |
| Ошибка «не можем прочитати файл» | пут/права | проверьте пут; вход = `-` или stdin |

## 9. Учебние примери

```bash
# 1. Простий предложену
echo "Я читам новий книгу." | rusido translate        # Я читам новий книгу.

# 2. Множественое числ и родительний
echo "У мне нет книго." | rusido validate             # валиден: да

# 3. Глагол с основой на согласний
echo "Он идет в город." | rusido translate            # Он идет в город.
# («идет» переведен через NLP; падеж «город» зависит от разбора, смотрем. ограничения)

# 4. Сквозной контур: перевод и проверка
echo "Ми читами книго." | rusido validate             # валиден: да

# 5. Ошибка с исправлением
echo "Я читаш книгу." | rusido validate
# [R001] … несогласованость … (вариант: читам)
```
