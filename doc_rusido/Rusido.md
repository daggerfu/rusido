# РУСИДО — ПОЛНАЯ КОНЦЕПЦИЯ  
## Регуляризирований руский язику 

---

# 1. ОБЩАЯ КОНЦЕПЦИЯ

**Русидо** — искуствений язику на руский лексической базе с регулярной аглютинативной граматикой.

Название: **Рус + идо** — «упорядочений руский».

Цель:

> Сохранить узнаваемость руский слово, но убрать исключения, нерегулярность и сложность граматики.

Принципи:

1. Одно правил → один результат.
2. Нет граматических исключений.
3. Руский корени сохраняются.
4. Граматика полностью регулярна.
5. Каждое граматическое значение виражается отдельной морфемой.

Тип язико:

- аглютинативний;
- синтетический в словоизменении;
- аналитический в сложний конструкциях.

# 2. АЛФАВИТ, ФОНЕТИКА, ОРФОГРАФИЯ

## 2.1. Алфавит

29 букв:

```
А Б В Г Д Е Ж З И Й К Л М Н О П Р С Т У Ф Х Ц Ч Ш Щ Ь Ю Я
```

Строчние:

```
а б в г д е ж з и й к л м н о п р с т у ф х ц ч ш щ ь ю я
```

## 2.2. Отсутствующие букви

| Руский | Замена |
|---|---|
| е | е |
| и | и |
| е | е |
| ь | ь |

Примери:

```
елка → елка
черний → черний
етот → етот
обьект → обьект
```

## 2.3. Гласние

```
а е и о у ю я
```

Произношение:

| Буква | Звук |
|---|---|
| а | [а] |
| о | [о] |
| у | [у] |
| и | [и] |
| е | [е] / [йе] |
| я | [а] с мягкостью / [йа] |
| ю | [у] с мягкостью / [йу] |

Редукции нет: `вод`, `молок` читаются как написани.

## 2.4. Согласние

```
б в г д ж з й к л м н п р с т ф х ц ч ш щ
```

Мягкость — перед `е, и, я, ю, ь`.

`ь` обозначает мягкость и заменяет руский `ь`:

```
обьект, подьезд, сьезд
```

`ь` запрещен.

## 2.5. Ударение

Ударение всегда на предпоследнем слоге:

```
кни́га → книг
маши́на → машин
рабо́тот → работ
```

При словоизменении ударение не меняется.

## 2.6. Удвоение согласние

Удвоение согласние запрещени. В любом слове два одинаковие согласние подряд
сокращаются до одной:

```
аглютинативний → аглютинативний
руский → руский
клас → клас
```

Правил применяется после замени запрещених букв (§2.2) и охвативает все слов,
включая основу и афикси.

# 3. СУЩЕСТВИТЕЛЬНИЕ

## 3.1. Структура

```
Корен + Числ + ПАДЕЖ
```

Основа — руский корен без окончания:

| Руский | Основа |
|---|---|
| столу | столу |
| вод | водио |
| книг | книгио |
| дверу | двер |
| арми | арми |

## 3.2. Род

Обязательного рода нет.

Для одушевлених при необходимости:

- мужской: `-ец`
- женский: `-ица`

Пример:

```
учител → учителец / учителица
```

## 3.3. Числ

Только два число:

| Числ | Окончание |
|---|---|
| Единственое | ∅ |
| Множественое | -и |

Примери:

```
столу → столи
книгио → книго
дом → доми
```

**Двойственого число нет.** Для два предметов используется множественое числ:

```
два столи
два собаки
```

## 3.4. Падежи

Четире падежа:

| Падеж | Значение | Окончание |
|---|---|---|
| Именительний | субьект | ∅ |
| Винительний | обьект | -у |
| Родительний | принадлежность | -о |
| Дательний | адресат | -е |

## 3.5. Парадигма

Основа `столу`:

| Падеж | Ед. ч. | Мн. ч. |
|---|---|---|
| Они. | столу | столи |
| Вин. | столе | столиу |
| Род. | столо | столио |
| Дат. | столе | столие |

Основа `книгио`:

| Падеж | Ед. ч. | Мн. ч. |
|---|---|---|
| Они. | книгио | книго |
| Вин. | книгу | книгиу |
| Род. | книго | книгио |
| Дат. | книге | книгие |

Примери:

```
Я видем книгу.
У мене нет книго.
Я давам книгу брате.
```

# 4. ПРИЛАГАТЕЛЬНИЕ

Прилагательние **не изменяются** по роду, числе и падежу.

Структура:

```
ОСНОВА + -ий
```

Примери:

```
красивий
новий
болший
синий
```

Прилагательное всегда перед существительним:

```
красивий дом
новий книго
в болший доме
```

Степени сравнения:

```
более красивий
самий красивий
```

Кратких форм нет:

```
дом красивий
```

# 5. МЕСТОИМЕНИЯ

## 5.1. Личние

| Лицу | Ед. ч. | Мн. ч. |
|---|---|---|
| 1 | я | ми |
| 2 | ти | ви |
| 3 | он | они |

Двойственого число у местоимений нет.

## 5.2. Косвение форми

| Прямая | Косвеная |
|---|---|
| я | мне |
| ти | тебе |
| он | нему |
| ми | нам |
| ви | вам |
| они | ним |

Примери:

```
Я идем к тебе.
Он говорит с ним.
Она дала книгу мне.
```

## 5.3. Притяжательние

Не изменяются:

```
мой, твой, его, наш, ваш, их
```

Примери:

```
мой дом
твой книг
наш город
```

## 5.4. Указательние

```
етот, тот, такой
```

## 5.5. Вопросительние

```
кто, што, какий, кторий, где, куда, откуда, когда, почему, как, сколько
```

| 1 | одн |
| 2 | два |
| 3 | три |
| 4 | четир |
| 5 | пят |
| 6 | шест |
| 7 | сем |
| 8 | восем |
| 9 | девят |
| 10 | десят |

## 6.2. 11–19

```
однадек, дванадек, тринадек, четирнадек, пятнадек,
шестнадек, семнадек, восемнадек, девятнадек
```

## 6.3. Десятки

```
двадек, тридек, четирдек, пятдек,
шестдек, семдек, восемдек, девятдек
```

## 6.4. Сотни и тисячи

```
сто, двесто, тристо, четирсто, пятсто
однтис, дватис, тритис, четиртис, пятис
```

## 6.5. Согласование

| Числ | Существительное |
|---|---|
| 1 | единственое |
| 2 и болший | множественое |

Примери:

```

```

Если количество понятний, числительное можно опустить, но существительное остается в множественом числе:


Суфикс `-они`:

```
одним, дваим, триим, четирим
```

# 7. ГЛАГОЛИ

Глагольная система полностью регулярна. Спряжений и исключений нет.

## 7.1. Инфинитив

```
ОСНОВА + -ти
```

Примери:

```
читати, делати, любити, ити, говорити
```

Основа — инфинитив без `-ти`:

```
чита-, дело-, любим-, говорим-
```

## 7.2. Настоящее врему

Окончания:

| Лицу | Ед. ч. | Мн. ч. |
|---|---|---|
| 1 | -м | -ми |
| 2 | -ш | -тот |
| 3 | -т | -ни |

Пример `читати`:

| Лицу | Форма |
|---|---|
| я | читам |
| ти | читаш |
| он | читат |
| ми | читами |
| ви | читам |
| они | читани |

Если основа на согласний, вставляется `-е-`:

`ити` → основа `ид-`:

| Лицу | Форма |
|---|---|
| я | идеми |
| ти | идеш |
| он | идет |
| ми | идеми |
| ви | идете |
| они | идени |

## 7.3. Прошедшее врему

| Числ | Окончание |
|---|---|
| Единственое | -л |
| Множественое | -ли |

Примери:

```
я читал
они читали
```

**Двойственого число нет:** для два субьектов используется `-ли`.

## 7.4. Будущее врему

```
будти + инфинитив
```

Примери:

```
Я будеми будти читати.
Они будени работати.
```

## 7.5. Повелительное наклонение

Основа на согласний: `+ и`

```
ити → идем
писати → писам
```

Основа на гласний: `+ й`

```
делати → делай
читати → читай
```

Множественое числ: `+ тот`

```
идите, читам, делам
```

## 7.6. Условное наклонение

```
би + прошедшее врему
```

Примери:

```
Я би читал.
Они би пришли.
```

## 7.7. Отрицание

```
не + глагол
```

```
Я не читам.
Он не идет.
Они не работани.
```

## 7.8. Страдательний залог

```
обьект + се + глагол
```

```
Книг се читат.
Дом се строт.
```

## 7.9. Безличние конструкции

```
ну + состояние + косвеное местоимение
```

```
Ну холодий мне.
Ну плохий нему.
```

## 7.10. Вид

Обязательного вида нет. Используются частици:

```
продолжати
уже
начати
```

Примери:

```
Я продолжам читати.
Я уже прочел книгу.
Я начам работати.
```

## 7.11. Причастия и деепричастия

Специальних форм нет. Используются конструкции с `кторий`, `когда`, `потому што`.

```
человек, кторий читат
человек, кторий прочел книгу
книг, кторий се писал
```

# 8. СИНТАКСИС

## 8.1. Базовий порядок

```
SVO
```

Пример:

```
Я читам книгу.
```

Порядок может меняться для виделения, но SVO предпочтителен.

## 8.2. Именая група

```
прилагательное + существительное
```

```
болший дом
новий книго
```

Несколько прилагательних:

```
общее качество → размер → цвет → происхождение
```

## 8.3. Владение

```
у + обладатель + естет + обьект
```

Пример:

```
У мне естет книг.
У нему естет два собаки.
```

В настоящем времо `естет` может опускаться при простий характеристике:

```
Я студент.
```

## 8.4. Отрицание

```
не + сказуемое
```

Отсутствие:

```
нет
```

```
У мне нет книго.
```

## 8.5. Вопросиу

Порядок словио не меняется. Возможна частица `ли`:

```
Ти читаш книгу?
Читаш ли ти книгу?
```

## 8.6. Предлоги

Предлоги не изменяются и стояни перед существительним.

Основние:

```
в, на, у, к, из, от, с, без, для, о, од
```

Управление в даной концепции унифицировано:

- статика: дательний — `в доме`, `на столе`;
- направление: винительний — `в дом`, `на столе`;
- адресат: дательний — `к брате`;
- источник: родительний — `из домо`, `от друго`;
- отсутствие: родительний — `без книго`;
- цель: родительний — `для друго`;
- тема: дательний — `о городе`.

Примери:

```
в доме
на столе
к брате
из домо
без книго
для друго
о городе
```

## 8.7. Союзи

```
и, или, но, а, если, когда, потому што, штоби, также, тоже, однако, либо, так как
```

## 8.8. Частици

```
не, да, нет, только, уже, ешо, же, может
```

## 8.9. Придаточние

Определительние:

```
человек, кторий читат книгу
```

Времение:

```
Когда я пришел, он спал.
```

Условние:

```
Если я будеми будти знати, я будем сказати.
```

# 9. СЛОВООБРАЗОВАНИЕ

Принцип:

```
Корен + ПРИСТАВКА + СУФИКС
```

Один афикс — одно основное значение.

## 9.1. Приставки

```
в-/в- — внутрь
ви- — наружу
за- — начало / за предел
до- — завершение
пере- — повторение / изменение
про- — через / полностью
от- — удаление
под- — приближение / низкий
при- — прибитие / присоединение
разио- — разделение / усиление
с- — совместность / вниз
без- — отсутствие
```

Примери:

```
войти, вийти, записати, дописати,
переписати, прочитати, отойти,
подойти, прийти, разделити,
сделати, бездом
```

## 9.2. Основние суфикси

Лицо и професии:

```
-ник, -ница, -ец, -ица, -ист
```

Примери:

```
работник, работница, городец, математист
```

Действие:

```
-ова, -ирова, -иза
```

```
плановати, анализировати, модернизати
```

Абстрактние понятия:

```
-ост, -ство, -ние, -ция
```

```
свободност, общество, чтение, организация
```

Предмети и инструменти:

```
-ло, -ка, -ница, -ник
```

```
писал, книжка, сахарница, чайник
```

Уменьшение и увеличение:

```
-ок, -ик, -чик, -ищ
```

```
домок, столик, листчик, домищ
```

Качество:

```
-ий, -о, -ней, -ейш
```

```
красивий, бистрий, бистрий, бистрейш
```

Отношение:

```
-ск, -н, -ов, -ин
```

```
руск, водний, отцов, мамин
```

Место:

```
-ня, -ище, -ник
```

```
готовня, городище, лесник
```

# 10. СВОДНАЯ ГРАМАТИКА

## Существительное

```
корен + числ + падеж
```

Числ:

```
∅ / -и
```

Падеж:

```
∅ / -у / -о / -е
```

## Прилагательное

```
корен + -ий
```

Не изменяется.

## Глагол

Инфинитив:

```
-ти
```

Настоящее:

```
1 ед. -м    1 мн. -ми
2 ед. -ш    2 мн. -тот
3 ед. -т    3 мн. -ни
```

Прошедшее:

```
ед. -л
мн. -ли
```

Будущее:

```
будти + инфинитив
```

Условное:

```
би + прошедшее
```

Пасив:

```
се + глагол
```

## Синтаксис

```
SVO
```

Причастия:

```
кторий + глагол
```

## Числ

Только:

```
единственое
множественое
```

**Двойственое числ отсутствует.**

# 11. ОБРАЗЕЦ ТЕКСТА

Руский:

> Мой брат жит в болший красивий доме. У он бует два собаки. Я любим читати новий книго. Вчера я прочел интересий книгу, которую написал известий автор. Завтра я будем будти писати письму.

Русидо:

> Мой брат жит в болший красивий доме.  
> У нему естет два собаки.  
> Я люблим читати новий книгиу.  
> Вчера я прочел интересий книгу, кторий се писал од известий автор.  
> Завтра я будеми будти писати письму.

# 12. ИТОГ

Русидо — етот:

- руский словар;
- регулярная аглютинативная граматика;
- четире падежа;
- два число: единственое и множественое;
- отсутствие родових согласований;
- неизменяемие прилагательние;
- регулярная глагольная система;
- аналитические причастние и пасивние конструкции;
- фиксирований порядок SVO как база.

Главний формула:

```
Руский Корен
+ РЕГУЛЯРНАЯ ГРАМАТИКА
+ АГЛЮТИНАТИВНОЕ СЛОВООБРАЗОВАНИЕ
= РУСИДО
```
