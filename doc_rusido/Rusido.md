# 1. ОБЩАЯ КОНЦЕПЦИЯ

**Русидо** — искуствений язик на руский лексической базе с регулярной аглютинативний граматикой.

Название: **Рус + идо** — «упорядочений руский».

Цель:

> Сохранить узнаваемость руский слови, но убрать исключения, нерегулярность и сложность граматики.

Принципи:

1. Одно правил → один результат.
2. Нет граматических исключений.
3. Руский корени сохраняются.
4. Граматика полностью регулярна.
5. Каждое граматическое значение виражается отдельной морфемой.

Тип язико:

- аглютинативний;
- синтетический в словоизменении;
- аналитический в сложний конструкциях.

## 1.1. Три слоя письменого текста

Русидо определяется не только граматикой словио, но и правилие
обработки текста, кторий не является обичний руский слове.
Виделяются три слоя:

1. **Внутрений язик** — лексика, морфология, синтаксис.
2. **Орфографическая оболочка** — алфавит, регистр, пунктуация,
   правили записи (§2.7—2.8, §6.7).
3. **Внешние токени** — имени, оригинальние названия, абревиатури,
   неадаптирование заимствования и цифровие виражения
   (§2.9, §9.3).

Не каждий фрагмент входного текста проходит через морфологический
анализатор: внешние токени распознаются на уровне оболочки и
сохраняют исходное написание.

# 2. АЛФАВИТ, ФОНЕТИКА, ОРФОГРАФИЯ

## 2.1. Алфавит

29 букв:

```
А Б В Г Д Е Ж З И Й К Л М Н О П Р С Т У Ф Х Ц Ч Ш Щ Ь Ю Я
```

Строчние:

```
а б в г д е ж з и й к л м н о п р с т у ф х ц ч ш щ ь ю я
```

## 2.2. Отсутствующие букви

| Руский | Замена |
|---|---|
| е | е |
| и | и |
| е | е |
| ь | ь |

Примери:

```
елк → елк
черний → черний
ето → ето
обьект → обьект
```

Небольшой закритий набор служебних словио имеет уникальние форми, не виводимие
правилие замени, и фиксируется словаре:

```
што → што, штоби → штоби, кторий → кторий, ешо → ешо
```

## 2.3. Гласние

```
а е и о у ю я
```

Произношение:

| Буква | Звук |
|---|---|
| а | [а] |
| о | [о] |
| у | [у] |
| и | [и] |
| е | [е] / [йе] |
| я | [а] с мягкостью / [йа] |
| ю | [у] с мягкостью / [йу] |

Редукции нет: `водо`, `молок` читаются как написани.

## 2.4. Согласние

```
б в г д ж з й к л м н п р с т ф х ц ч ш щ
```

Мягкость — перед `е, и, я, ю, ь`.

`ь` имеет два регулярних употребления:

1. **Мягкость** — в конце основи (двер → двер-) и перед гласними внутри
   основи (арми, письм).
2. **Замена запрещеного `ь`** — на месте руский твердий знака; такой `ь`
   Не смягчает согласную и читается как разделительний:

```
обьект → обьект [тв. т], подьезд → подьезд, сьезд → сьезд
```

`ь` запрещен.

### Конечний мягкий знак

Конечний `ь` исходного руский слови не входит в основу
Русидо и удаляется при нормализации.

После удаления `ь` полученая основа используется без изменений
при присоединении падежних окончаний, глагольних окончаний
и словообразовательних суфиксов.

Сохранение `ь` перед афиксами не допускается.
Вставка дополнительного `ь` между основой и афиксом
также не допускается.

Примери:

```
двер → двер-
двер + -е → двере
двер + -ие → дверие
тетрад → тетрад-
тетрад + -е → тетраде
тетрад + -ий → тетрадий
```

## 2.5. Ударение

Ударение не является различительним признаком и не регламентируется:
он сохраняется от исходного руский слови (книѓ, маши́на, рабо́тот).
При словоизменении ударение Не смещается — он остается на тот же слоге
основи, даже если добавление афикси меняют счет слогов:

```
сто́л → сто́лу, сто́лиу (ударение на основе, афикси безударние)
```

Для односложних словио ударение падат на единствений слог.

## 2.6. Удвоение согласние

Удвоение согласние запрещени. В любом слове два одинаковие согласние подряд
сокращаются до одной:

```
аглютинативний → аглютинативний
руский → руский
клас → клас
```

Правил применяется после замени запрещених букв (§2.2) и охвативает все слов,
включая основу и афикси. Он не применяется к внешним токенам (§2.9, §9.3).

## 2.7. Регистр

Регистр букв не изменяет лексическое значение,
граматическую категорию или морфологическую форму словиу.

Русидо различает прописние и строчние букви. Регистр не меняет
значение слови, его произношение или граматические свойства.

### Стандартное написание

В стандартном режиме:

- первий слов предложени начинается с заглавной букви;
- имени собствение начинаются с заглавной букви;
- абревиатури сохраняют установлений регистр;
- обичний слови пишутся строчними буквами.

### Нестандартний регистр

Полностью прописное или строчное написание допускается
как стилистическое отклонение. Названия и заголовки можени
использовать произвольний регистр.

```
Я читам.
Я ЧИТАМ.
я читам.
```

При лексической нормализации регистр учитивается
только как орфографическое оформление. Абревиатури
и внешние токени не подвергаются автоматической нормализации.

Регистр не является основанием для отклонения текста
граматическим анализатором. Орфографический валидатор
может видавать предупреждения о несоблюдении стандартного
регистра.

## 2.8. Пунктуация

### 2.8.1. Общий принцип

Русидо использует руский систему пунктуации. Знаки препинания
виполняют синтаксическую и просодическую функцию: отделяют
предложени, указивают паузи, виделяют прямую речь и цитати.

Знаки препинания не являются морфемами, не входини в состав
слови и не изменяют его форму. Пунктуация не влияет
на морфологическую структуру словиу.

### 2.8.2. Инвентарь знаков

```
. , ; : ? ! … — - « » " " ( ) [ ] /
```

Дефис `-` используется внутри лексического токена (§2.12.1).
Тире `—` отделяется пробелами и оформляет паузу или реплику.
Основние кавички — `« »`; `" "` допускаются в вложених
цитатах и внутри внешних текстов.

### 2.8.3. Конец предложени

- `.` — конец повествовательного предложени;
- `?` — вопрос;
- `!` — восклицание;
- `…` — незавершеность или пауза.

Пробел ставится после знака препинания, но не перед ним.
Согласование подлежащего и сказуемого проверяется
в пределах одного предложени.

```
Я читам.
Ти читаш?
Он читат!
Я читам …
```

### 2.8.4. Запятая, точка с запятой, двоеточие и тире

- запятая разделяет однородние члени, водние слови,
  обращения и части сложний предложени;
- точка с запятой разделяет части, внутри которих
  уже ести запятие;
- двоеточие водит пояснение, перечисление или прямую речь;
- тире оформляет паузу, уточнение, противопоставление
  и реплики диалога.

```
Я читам: книгу.
Я читам — книгу.
Я читам (книгу).
```

### 2.8.5. Прямая речь, цитати и диалог

Прямая речь виделяется кавичками `« »`. Слови авторо
присоединяются через двоеточие или тире:

```
Он говорил: «Я читам».
«Ти читаш?» — он читат.
```

Реплики диалога начинаются с тире:

```
— Я читам.
— Ти читаш?
```

Вложеная цитата заключается в `" "`. Пунктуация внутри
цитат и внешних текстов сохраняется (§1.1, §9.3).

### 2.8.6. Скобки и косая черта

Круглие скобки виделяют пояснение, квадратние — вставку
в цитате. Косая черта разделяет варианти или части
неадаптированого написания.

### 2.8.7. Дефис и тире

Дефис соединяет компоненти одного слови и не отделяется
пробелами (`тук-тук`, §2.12.1). Тире отделяется пробелами
и соединяет части текста, но не слови.

## 2.9. Имени собствение

Имени собствение подразделяются на два типа:

1. Адаптирование — оформляются по орфографическим
   и граматическим правилие Русидо.
2. Оригинальние — сохраняют исходное написание,
   регистр и диакритические знаки.

К оригинальним имение не применяются:
- замена букв (§2.2);
- сокращение удвоених согласних (§2.6);
- автоматическая транслитерация.

Оригинальние имени можени получати граматические
показатели через дефис:

Ана-у
Ана-о
Ана-е

В составе полного имено показатель присоединяется
к последний компоненту:

Иван Петров-у.

## 2.10. Междометия и звукоподражания

### 2.10.1. Определение

Междометия и звукоподражания образуют отдельний
лексико-граматический клас — експресивние слови.

Они не относятся к существительним, глаголам,
прилагательним или служебним словие.

### 2.10.2. Подкласи

Различаются:

1. Междометия — виражают емоции, реакции,
   призиви и волеизьявление.
2. Звукоподражания — воспроизводят звукиу,
   шуми и голоса живих существ.

Примери междометий: `О`, `Ай`, `Ура`, `Ау`.
К междометиям относятся также приветствия (`привет`,
`здравствуй`, `здравствуйте`), зарегистрирование
в лексиконе (§9.3).

Примери звукоподражаний: `Мяу`, `Гав`, `Бум`, `Тук-тук`.

### 2.10.3. Граматические свойства

Експресивние слови:

- не имеют граматического рода;
- не изменяются по числе;
- не склоняются;
- не спрягаются;
- не согласуются с другими словие;
- не требуют падежного управления.

Експресивное слов может самостоятельно
образовивать висказивание или входити в состав
предложени как отдельний компонент.

### 2.10.4. Орфография

Допускаются:

- повторение: `ха-ха`, `тук-тук`;
- дефисние сочетания: `динь-дон`;
- удлинение букв как експресивний прием: `Ааа`.

Удлинение букв не является граматическим
словоизменением. Пунктуация определяется общими
правилие (§2.8).

## 2.11. Абревиатури

### 2.11.1. Определение

Абревиатури являются отдельним лексическим класе.
Они обозначают сокращение наименования организаций,
понятий, учреждений и других обьектио.

### 2.11.2. Написание

Абревиатури сохраняют установленое написание,
включая регистр букв.

Абревиатури не проходят автоматическую
орфографическую нормализацию Русидо.

Примери:

```
СР
ООН
ИИ
МГУ
НАТО
```

### 2.11.3. Произношение

Произношение абревиатури определяется словарной записью.

Различаются:

1. Буквеное чтение — произношение названий букв.
2. Словесное чтение — произношение как обичний слови.

Написание абревиатури не определяет автоматически
способ ее произношения.

### 2.11.4. Граматическое поведение

Абревиатури по умолчанию являются несклоняемими
и не изменяются по числе.

Если требуется словоизменение, он должно будти
явно определено словарной записью.

## 2.12. Дефисние и апострофние написания

### 2.12.1. Дефис

Дефис `-` допускается внутри одного лексического токена.

Он используется:

- в дефисних словие;
- в составних имение собствених (§9.4.4);
- в звукоподражаниях (§2.10);
- в словарно закреплених составних служебних словие;
- при отделении окончания от неадаптированой основи,
  если такой склонение разрешено словаре (§9.4.3).

Дефис сам по себе не обозначает границу
между отдельними словие.

Примери:

```
по-руски
Йошкар-Ола
тук-тук
```

### 2.12.2. Апостроф

Апострофи `'` и `’` не входини в алфавит
и стандартную орфографию Русидо.

Они допускаются только внутри неадаптированих
внешних токенов, если присутствуют в исходном
написании имено или заимствования (§9.3, §9.4).

Внешние токени сохраняют исходное написание
и не проходят автоматическую нормализацию.

Пример: `O'Connor`.

Апостроф не используется как стандартний
морфологический разделитель.

### 2.12.3. Токенизация

Токенизатор различает:

1. Слови и составние лексические токени.
2. Пробели между словие.
3. Пунктуационие знаки.
4. Внешние токени.

Дефис внутри слови не создает границу
между отдельними лексическими токенами.

Апостроф внутри внешнего токена не создает
границу между токенами.

Пунктуация отделяется от словио, если он
не входит в зарегистрированое внешнее написание.

### 2.12.4. Словарная обработка

Дефисние слови должни иметь словарную запись
или виводиться по явно установленому правиле.

Неадаптирование имени и заимствования
с апострофом сохраняются без изменений.

Неизвестний последовательности с апострофом
не должни автоматически преобразовиваться
в обичний слови Русидо.

# 3. СУЩЕСТВИТЕЛЬНИЕ

## 3.1. Структура

```
Корен + Числ + ПАДЕЖ
```

Основа — руский корен без окончания:

| Руский | Основа |
|---|---|
| стол | столу |
| вод | вод |
| книг | книгио |
| двер | двер |
| арми | арми |

## 3.2. Род и обозначение пола

**Принцип.** Русидо — язик без граматического рода, но не без средств
лексического обозначения пола.

Отсутствие граматического рода означает, што:

- местоимение `он` универсально для 3-го лици единственого числи
  (руский `он`, `он` переводятся как `он`, §5.1);
- прилагательние неизменяеми и не согласуются с имене (§4);
- глагольние форми не различают род: прошедшее врем виражает только числ
  (§7.3);
- пол различается лексически — суфиксами `-ец` / `-ица`, `-ник` / `-ница`
  в названиях професий и ролей (§9.2).

Суфикси `-ец`/`-ица` — словообразовательние, а не согласовательние.
Они позволяют отдельно назвать мужчину и женщину, но не требуют изменения
других словио в предложене: `учителец дал книгу` и `учителиц дал книгу`
одинаково граматични.

Пример:

```
учител → учителец / учителиц
```

## 3.3. Числ

Только два числи:

| Числ | Окончание |
|---|---|
| Единственое | ∅ |
| Множественое | -и |

Примери:

```
стол → столи
книгио → книги
дом → доми
```

**Двойственого числи нет.** Для два предметов используется множественое числ:

```
два столи
два собаки
```

## 3.4. Падежи

Четире падежа:

| Падеж | Значение | Окончание |
|---|---|---|
| Именительний | субьект | ∅ |
| Винительний | обьект | -у |
| Родительний | принадлежность | -о |
| Дательний | адресат | -е |

## 3.5. Парадигма

Основа `стол`:

| Падеж | Ед. ч. | Мн. ч. |
|---|---|---|
| Они. | столу | столи |
| Вин. | столе | столиу |
| Род. | столо | столио |
| Дат. | столе | столие |

Основа `книгио`:

| Падеж | Ед. ч. | Мн. ч. |
|---|---|---|
| Они. | книгио | книги |
| Вин. | книгу | книгиу |
| Род. | книго | книгио |
| Дат. | книге | книгие |

Примери:

```
Я видем книгу.
У мне нет книго.
Я давам книгу брате.
```

## 3.6. Имени собствение в падежах

Адаптирование имени собствение склоняются
по общей модели существительних.

Оригинальние имени собствение сохраняют
исходную форму и получани падежний показатель
через дефис:

Именительний: Ана
Винительний: Ана-у
Родительний: Ана-о
Дательний: Ана-е

Множественое числ личних именио не образуется
автоматически.

# 4. ПРИЛАГАТЕЛЬНИЕ

Прилагательние **не изменяются** по роду, числе и падежу.

Структура:

```
ОСНОВА + -ий
```

Примери:

```
красивий
новий
болший
синий
```

Прилагательное всегда перед существительним:

```
красивий дом
новий книги
в болший доме
```

Степени сравнения:

```
более красивий
самий красивий
```

Кратких форм нет:

```
дом красивий
```

# 5. МЕСТОИМЕНИЯ

## 5.1. Личние

| Лиц | Ед. ч. | Мн. ч. |
|---|---|---|
| 1 | я | ми |
| 2 | ти | ви |
| 3 | он | они |

Двойственого числи у местоимений нет.

Местоимение `он` универсально и безродово: руский `он`, `он` переводятся
как `он` (он дал книгу → он дал книгу). Отдельних форм `он`/`он` в Русидо нет.

## 5.2. Косвение форми

Косвение форми личних местоимений:

| Именительная форма | Косвеная форма |
|---|---|
| я | мне |
| ти | тебе |
| он | нему |
| ми | нам |
| ви | вам |
| они | ним |

Косвеная форма используется после предлогов и в других
позициях, требующих косвеного местоимения.

Примери:

```
Я идеми к тебе.
Он идет к нему.
Он дал книгу мне.
У мне ест книг.
С ним я идем.
```

## 5.3. Притяжательние

Не изменяются:

```
мой, твой, его, наш, ваш, их
```

Примери:

```
мой дому
твой книг
наш город
```

Форма `его` — притяжательное определение: он обозначает
принадлежность третьему лице и не заменяет косвеную форму `нему`.

```
его книг
его дом
я видем его книгу
```

Различаем:

- `нему` — косвеная форма личного местоимения;
- `его` — притяжательная форма.

## 5.4. Указательние

```
етот, тот, такой
```

## 5.5. Вопросительние и относительние слови

```
кто, што, какий, кторий, где, куда, откуда, когда, почему, как, сколько
```

`какий` — вопросительное местоименое слов. Используется для запроса
признака, типа или вибора обьекто. Не изменяется по роду и числе.

Примери:

```
Какий книг ти читаш?
Какий дом ти хотел?
Какий человек пришел?
```

`кторий` — неизменяемий относительний маркер. Водит придаточное
определительное предложен и связивает его с существительним
в главний части.

Примери:

```
Человек, кторий читат.
Книг, кторий лежани.
Доми, кторий стояни.
```

`какий` и `кторий` не являются взаимозаменяемими:

- `какий` задает вопросу о признаке или разновидности;
- `кторий` водит относительное придаточное.

# 6. ЧИСЛИТЕЛЬНИЕ

Числительние не изменяются.

## 6.1. 0–10

| Числ | Русидо |
|---|---|
| 0 | нол |
| 1 | одн |
| 2 | два |
| 3 | три |
| 4 | четир |
| 5 | пят |
| 6 | шест |
| 7 | сем |
| 8 | восем |
| 9 | девят |
| 10 | десят |

## 6.2. 11–19

Числи 11–19 образуются присоединением суфикса `-надек`
к основе числительного от 1 до 9.

```
одн + надек = однадек → однадек
два + надек = дванадек
три + надек = тринадек
четир + надек = четирнадек
пят + надек = пятнадек
шест + надек = шестнадек
сем + надек = семнадек
восем + надек = восемнадек
девят + надек = девятнадек
```

После присоединения суфиксов применяется правил
устранения удвоених согласних (§2.6).

## 6.3. Десятки

```
двадек, тридек, четирдек, пятдек,
шестдек, семдек, восемдек, девятдек
```

## 6.4. Сотни и тисячи

Сотни и тисячи образуются композиционо.

Сотни:

```
100 = сто
200–900 = основа числительного (2–9) + сто
```

Тисячи:

```
1000–9000 = основа числительного (1–9) + тис
```

При соединении основи и разрядного показателя
действует правил устранения удвоених согласних (§2.6).

Примери:

```
600 = шест + сто = шестсто
700 = сем + сто = семсто
5000 = пят + тис = пятис
6000 = шест + тис = шестис
7000 = сем + тис = семтис
```

Составние числи образуются перечислением ненулевих
разрядов через пробел в порядке убивания:

```
ТИСЯЧИ + СОТНИ + ДЕСЯТКИ + ЕДИНИЦИ
```

Нулевие разряди пропускаются.

Примери:

```
21 = двадек одн
125 = сто двадек пят
600 = шестсто
1001 = однтис одн
2026 = дватис двадек шест
7650 = семтис шестсто пятдек
```

Система охвативает числиу от 0 до 9999.
Числи за пределами етоо диапазона записиваются цифрами
до ведения новий разрядних показателей.

## 6.5. Согласование

| Значение | Существительное |
|---|---|
| Ровно 1 | единственое |
| 0 и 2 или болший | множественое |

Согласование определяется полним числовим значением,
а не последний компонентом составного числительного.

Примери:

```
одн стол
два столи
нол столи
двадек одн столи
сто одн столи
```

Если количество понятний, числительное можно опустить, но существительное остается в множественом числе:

```
столи = два столо и болший
```

## 6.6. Порядковие

Суфикс `-они`:

```
одним, дваим, триим, четирим
```

В составном числительном `-они` присоединяется к последний компоненту:

```
сто двадек пят → сто двадек пятим   (125-й)
двадек три → двадек триим           (23-й)
```

## 6.7. Запись числио цифрами

Арабские цифри 0–9 разрешени.

Числ, записам цифрами, является полноценим
числовим виражением и не требует преобразования
в словесную форму.

Примери:

```
2026
3,14
-15
3/4
25%
1 000 000
17.11.2026
15:30
10–20
```

Для десятичних числио используется запятая.
Для разделения разрядов используется пробел.

Дата и врем расматриваются как специальние
числовие формати, а не как обичний составние
количествение числительние.

Согласование числовой записи:

- значение ровно 1 — единственое числ;
- остальние количествение значения — множественое числ.

Примери:

```
0 столи
1 стол
2 столи
21 столи
1,0 стол
1,5 столи
```

# 7. ГЛАГОЛИ

Глагольная система полностью регулярна. Спряжений и исключений нет.

## 7.1. Основа глагола

Каждая глагольная лексема имеет явно определеную
инфинитивную основу. По умолчанию он определяется удалением
окончания `-ти`.

Например:

```
жити → жи-
любити → любий-
читати → чита-
писати → писа-
прочитати → прочита-
```

Приставки, входим в состав лексеми, являются частью
основи и не добавляются на етапе спряжения.

Инфинитив образуется по модели `ОСНОВА + -ти`:

```
читати, делати, любити, ити, говорити
```

Вспомогательний глагол будущего времо:

```
будти → основа буд-.
```

Глагол `будти` является полноценой глагольной лексемой
и подчиняется общим правилие спряжения. Специальних
исключений для он нет.

Если глагол требует чередования, основи фиксируются словаре —
см. §7.1.1.

### 7.1.1. Аломорфи глагольной основи

По умолчанию каждая глагольная лексема имеет одну основу,
используемую в всех формах. Чередование согласних и гласних
внутри основи автоматически не производится.

Если лексема имеет несколько основ (аломорфов), все они
должни будти явно перечислени в словаре с указанием условий
их употребления. Аломорфи — варианти одной лексической
основи; такой чередование не считается нерегулярним
спряжением, если распределение однозначно определено словаре.

Для каждого глагола словару может содержать:

- инфинитивную основу;
- основу настоящего времо;
- основу прошедшего времо;
- основу повелительного наклонения.

По умолчанию все основи совпадают. Дополнительная основа
не может виводиться только из традиционой руский форми слови.

| Лема | Основная основа | Дополнительная основа |
|---|---|---|
| писати | писа- | — |
| любити | любий- | — |

Аломорфи применяются только в тот граматических позициях,
для которих они явно зарегистрировани. Если дополнительная
основа не указана, используется основная основа без изменений.

Пример:

Инфинитив: ити

| Форма | Основа |
|---|---|
| Инфинитив | и- |
| Настоящее | ид- |
| Прошедшее | ид- |
| Повелительное | ид- |

Образование форм:

```
ити
ид + е + м = идеми
ид + е + л = идел
ид + и = иди
```

Будущее врем образуется с инфинитивом:
`будеми ити`.

## 7.2. Настоящее врем

Окончания:

| Лиц | Ед. ч. | Мн. ч. |
|---|---|---|
| 1 | -м | -ми |
| 2 | -ш | -тот |
| 3 | -т | -ни |

Пример `читати`:

| Лиц | Форма |
|---|---|
| я | читам |
| ти | читаш |
| он | читат |
| ми | читами |
| ви | читам |
| они | читани |

Лексема `ести` (принимати пищу) имеет основу `ес-`.
Он спрягается по общему правиле для основ
на согласную с соединительной гласной `-е-`.

Парадигма:

| Лиц | Ед. ч. | Мн. ч. |
|---|---|---|
| 1 | есем | есеми |
| 2 | есеш | есете |
| 3 | есет | есени |

Форма `есет` не является формой глагола `ести`.

Парадигма вспомогательного глагола `будти`:

| Лиц | Форма |
|---|---|
| я | будеми |
| ти | будеш |
| он | будет |
| ми | будеми |
| ви | будете |
| они | будени |

Основа `буд-` оканчивается на согласную, поетому
перед личними окончаниями вставляется соединительная
гласная `-е-`.

Если основа на согласний, вставляется `-е-`:

`ити` → основа настоящего времо `ид-` (§7.1.1):

| Лиц | Форма |
|---|---|
| я | идеми |
| ти | идеш |
| он | идет |
| ми | идеми |
| ви | идете |
| они | идени |

## 7.3. Прошедшее врем

| Числ | Окончание |
|---|---|
| Единственое | -л |
| Множественое | -ли |

При основе на согласний вставляется соединительная `-е-` (как в §7.2):

```
ид + е + л = идел, мн. ч. идели
```

Примери:

```
я читал
они читали
он идел
```

Вспомогательний глагол `будти` также образует
прошедшее врем по общему правиле:

```
буд + е + л = будел
буд + е + ли = будели
```

**Двойственого числи нет:** для два субьектов используется `-ли`.

## 7.4. Будущее врем

Вспомогательний глагол будущего времо — `будти`.

- Лема: `будти`.
- Основа: `буд-`.

Личние форми совпадают с формами настоящего времо (§7.2):

| Лиц | Единственое числ | Множественое числ |
|---|---|---|
| 1-е | будеми | будеми |
| 2-е | будеш | будете |
| 3-е | будет | будени |

Будущее врем образуется сочетанием личной форми `будти`
с инфинитивом смислового глагола.

Глагол `будти` используется в два конструкциях:

1. Как вспомогательний глагол будущего времо:
   личная форма `будти` + инфинитив основного глагола.
2. Как связочний глагол будущего времо:
   субьект + личная форма `будти` + именая
   или качественая часть сказуемого.

В первий случае основной глагол сохраняет инфинитив.
В втором случае инфинитив отсутствует.

Примери вспомогательной конструкции:

```
я будеми читати
ти будеш читати
он будет читати
ми будеми читати
ви будете читати
они будени читати
```

Примери связочной конструкции:

```
Я будеми студент.
Он будет врач.
Дом будет красивий.
```

В связочной конструкции `будти` согласуется
с субьектом по лице и числе.

Глагол `будти` не является исключением из общей системи
спряжения. Его форми образуются по правилие §7.2.

## 7.5. Повелительное наклонение

Повелительное наклонение образуется от основи инфинитива
или от явно указаного аломорфа:

- основа на согласний: `+ и`;
- основа на гласний: `+ й`.

Чередование согласних при образовании повелительного
наклонения не производится, если он не указано
в словаре как отдельний аломорф.

Примери:

```
ити → иди (ид + и)
писати → писай
читати → читай
любити → любий
```

Форми типа `писай` не образуются из `писати` автоматически.
Для их использования необходимо отдельно зарегистрировать
соответствующий аломорф основи.

Множественое числ: `+ тот`

```
идите, читайте, делайте
```

## 7.6. Условное наклонение

```
би + прошедшее врем
```

Примери:

```
Я би читал.
Они би пришели.
```

## 7.7. Отрицание

```
не + глагол
```

```
Я не читам.
Он не идет.
Они не работани.
```

## 7.8. Страдательний залог

Каноническая пасивная конструкция:

```
обьект + се + глагол
```

Агент действия может будти указан необязательной
предложной групой:

```
од + существительное в родительном падеже
```

Примери:

```
Книг се читат.
Дом се строт.
Книг се писал.
Книг се писал од авторо.
```

Предложная група с `од` не образует отдельного типа
пасивной конструкции. Он только обозначает агента.

## 7.9. Безличние конструкции

```
ну + состояние + косвеное местоимение
```

```
Ну холодно мне.
Ну плохо нему.
```

## 7.10. Вид

Обязательного вида нет. Вид передается лексически: служебними глаголами
`начати` (начать) и `продолжати` (продолжати), а также частицей `уже`.

Вид не изменяет правили образования глагольних форм.
Если два лексеми образуют видовую пару, их связь
фиксируется в словаре:

```
читати — несовершений вид
прочитати — совершений вид
```

Приставка, входил в состав лексеми, включается
в ее основу:

```
читати → чита-
прочитати → прочита-
```

Врем и лиц образуются от полной основи лексеми
по общим правилие спряжения.

Примери:

```
Я продолжам читати.
Я уже прочитал книгу.
Я начам работати.
```

## 7.11. Причастия и деепричастия

Специальних форм нет. Используются конструкции с `кторий`, `когда`, `потому што`.

Относительний маркер `кторий` неизменяем. Он не согласуется
с определяемим существительним по роду, числе или падежу.
Глагол внутри относительного придаточного оформляется
по обичний правилие спряжения.

Примери:

```
человек, кторий читат
человек, кторий прочитал книгу
книг, кторий се писал
книг, кторий лежани
доми, кторий стояни
человеки, кторий работани
```

## 8.1. Базовий порядок

```

```

Пример:

```

```

Порядок может меняться для виделения, но SVO предпочтителен.

```

```

```

Несколько прилагательних:

```

```

## 8.3. Владение

Конструкция наличия:

```
у + обладатель (косвеная форма) + есет + обьект
```

Предикатор `есет` обозначает существование или наличие обьекто.
Он является инвариантним служебним предикатором,
а не формой глагола `ести`. Не изменяется по лицие,
числие и времие.

Конструкция:

```
у + обладатель (косвеная форма) + есет + обьект (именительний падеж)
```

Примери:

```
У мне ест книг.
У нему ест дом.
У ним ест собаки.
```

Обьект при `есет` употребляется в именительном падеже.
`есет` не требует родительного падежа.

Не следует смешивать:

- `есет` — имеется, существует;
- `ести` — принимати пищу;
- `есет` — форма 3-го лици единственого числи глагола `ести`.

`есет` — неизменяемий екзистенциальний предикатор,
виражающий существование, наличие или обладание.

`есет` не является обичний спрягаемим глаголом.
Он:

- не имеет лициу;
- не имеет числиу;
- не согласуется с обладателем;
- не согласуется с обьекте;
- не изменяется по родам;
- не принимат глагольних окончаний;
- не имеет инфинитива.

В конструкции обладания используется модель:

у + обладатель (дательний падеж) + есет + обьект.

Примери:

```
У мне ест книг.
У нему ест два собаки.
У ним ест новий дом.
```

В настоящем времо используется неизменяемий предикатор `есет`.

В будущем времо вместо `есет` используется личная форма `будти`.
Он согласуется с обладаемим обьекте по числе:

- единственое числ — форма 3-го лици единственого числи;
- множественое числ — форма 3-го лици множественого числи.

Примери:

```
У мне ест книг.
У мне будет книг.
У нему будет дом.
У ним будени собаки.
```

В конструкции обладания `есет` обязательно и не может опускаться
без изменения граматической конструкции.

В имених и качествених сказуемих настоящего времо
связка отсутствует:

```
Я студент.
Дом красивий.
Он учител.
```

Отсутствие связки в такой предложение является
нормативной нулевой связкой, а не пропуском `есет`.

Временая парадигма `есет` в дам версии
не устанавливается. Прошедшее и будущее врем
конструкции обладания требуют отдельного определения.

## 8.4. Отрицание

```
не + сказуемое
```

Отсутствие:

```
нет
```

После предикатора `нет` существительное ставится
в родительний падеж. Падежное окончание присоединяется
по общей модели склонения существительних.
Форма именительного падежа после `нет` не допускается.

Примери:

```
У мне нет книго.
У нему нет домо.
```

Конструкция отсутствия:

```
у + обладатель (косвеная форма) + нет + обьекто в родительном падеже
```

При отрицании существования родительний падеж
используется независимо от число обьекто.

## 8.5. Вопроси

В вопросе без частиц порядок словио не меняется. С частицей `ли` глагол
может предшествовать подлежащему (единственое регулярное отклонение от SVO):

```
Ти читаш книгу?
Читаш ли ти книгу?   (VSO допустимо только с «ли»)
```

## 8.6. Предлоги

Предлоги не изменяются и стояни перед существительним.

Основние:

```
в, на, у, к, из, от, с, без, для, о, од, под, до
```

Управление в дам концепции унифицировано:

- статика: дательний — `в доме`, `на столе`;
- направление: винительний — `в доме`, `на столе`;
- адресат: дательний — `к брате`;
- источник: родительний — `из домо`, `от друго`;
- отсутствие: родительний — `без книго`;
- цель: родительний — `для друго`;
- тема: дательний — `о городе`;
- обладатель и близость: дательний — `у мне`, `у брате`;
- совместность: дательний — `с нему`, `с друге`;
- агент пасива и источник: родительний — `од авторо`, `од друго` (см. §7.8).

`од + родительний падеж` обозначает агента действия
в пасивной конструкции.

Руский творительний падеж в Русидо не виделяется: форми на `-ом/-есем/-ями/-ами`
передаются дательним окончанием `-е` (`с брате → с брате`, `под столе → под столе`).
Ето постояное правил версии 1.0, а не временая евристика переводчика (D-013).

Примери:

```
в доме
на столе
к брате
из домо
без книго
для друго
о городе
у мне
с нему
од авторо
```

# 9. СЛОВООБРАЗОВАНИЕ

Один афикс — одно основное значение.

## 9.0. Общий порядок морфем

Морфемная структура производного слови:

```
ПРИСТАВКА + Корен + СУФИКС + СЛОВОИЗМЕНИТЕЛЬНИЙ ПОКАЗАТЕЛЬ
```

Необязательние морфеми можени отсутствовать.

Для глаголов:

```
ПРИСТАВКА + ГЛАГОЛЬНАЯ ОСНОВА + -ти
```

Приставки располагаются перед корене. Суфикси располагаются
после корено. Словоизменительние показатели располагаются
после словообразовательних морфем.

## 9.1. Приставки

Приставки образуют новий лексеми путе присоединения
к производящей основе.

Наличие начальной последовательности букв, совпадающей
с приставкой, само по себе не доказивает приставочного
происхождения слови.

Приставочное слов должно иметь:

- производящую лему;
- зарегистрированую приставку;
- производную основу;
- при необходимости — словарное значение.

Автоматическое чередование корено при присоединении
приставки не допускается, если он не описано
отдельним морфологическим правиле.

Список приставок:

```
в-/в- — внутрь
ви- — наружу
за- — начало / за предел
до- — завершение
пере- — повторение / изменение
про- — через / полностью
от- — удаление
под- — приближение / низкий
при- — прибитие / присоединение
раз- — разделение / усиление
с- — совместность / вниз
без- — отсутствие
```

Примери:

```
войти, вийти, записати, дописати,
переписати, прочитати, отойти,
подойти, прийти, разделити,
сделати, бездому
```

## 9.2. Основние суфикси

Лици и професии:

```
-ник, -ница, -ец, -ица, -ист
```

Примери:

```
работник, работниц, городец, математист
```

Действие:

```
-ова, -ирова, -иза
```

```
плановати, анализировати, модернизати
```

Абстрактние понятия:

```
-ост, -ство, -ние, -ция
```

```
свободио + ост = свободост, общество, чтение, организация
```

Предмети и инструменти:

```
-ло, -ка, -ница, -ник
```

```
писал, тетрадк, сахарниц, чайник
```

Уменьшение и увеличение:

```
-ок, -ик, -чик, -ищ
```

```
домок, столик, листчик, домищио
```

Качество:

```
-ий, -о, -ней, -ейш
```

```
красивий, бистро, бистрей, бистрейш

## 9.3. Заимствования

### 9.3.1. Общий принцип

Заимствование слови можени использоваться в два режимах:

- адаптированом;
- неадаптированом.

По умолчанию новий заимствования адаптируются,
если их можно записати средствами алфавита Русидо.

### 9.3.2. Адаптирование заимствования

Адаптирование заимствования проходят общую
орфографическую нормализацию Русидо (§2.2, §2.4).

Применяются следующий правили:

- `е → е`;
- `и → и`;
- `е → е`;
- конечний `ь` удаляется;
- удвоение согласние сокращаются до одной.

Дополнительний знак `ь` перед `е`, `ю`, `я`
не вставляется автоматически. Мягкость согласного
перед `е`, `ю`, `я` определяется правилие фонологии
Русидо.

После адаптации слов получат обичний
словарную основу и подчиняется общей морфологии.

Примери:

```
клас → клас
компьютер → компьютер
менеджер → менеджер
тунель → тунел
коф → коф
пюре → пюре
елк → елк
```

### 9.3.3. Неадаптирование заимствования

Неадаптирование заимствования сохраняют исходное
написание, включая символи, отсутствующие в алфавите
Русидо.

Они расматриваются как внешние неизменяемие токени
(§1.1) и не подвергаются автоматической нормализации.

По умолчанию такой слови не склоняются и не изменяются
по числе.

Если требуется регулярное изменение, словар должен
содержать адаптированую форму или явное описание
морфологической модели.

Примери:

```
software
deadline
machine learning
```

Для образования регулярних глагольних форм
заимствований глагол должен иметь словарную
лему, соответствующую §7.1.

### 9.3.4. Словарная запись

Словарная запись заимствования может содержать:

- исходное написание;
- адаптированое написание;
- режим: `adapted` / `external`;
- нормализованую основу;
- часть речи;
- модель словоизменения.

Если адаптированая форма не задана,
он определяется общими правилие нормализации.

## 9.4. Имени собствение

### 9.4.1. Общий принцип

Имени собствение являются частью лексики Русидо.
Они сохраняют свою идентичность, но подчиняются
правилие орфографии и граматики Русидо.

Различаются два режима записи:

1. Адаптированое имен.
2. Неадаптированое имен.

### 9.4.2. Адаптирование имени

Адаптирование имени записиваются буквами Русидо
и проходят стандартную орфографическую нормализацию.

К ним применяются общие правили:

- `е → е`;
- `и → и`;
- `е → е`;
- `ь → ь`, затем удаление конечного `ь`
  в соответствии с §2.4;
- сокращение удвоених согласних.

Адаптирование имени склоняются по общей системе
числи и падежа (§3).

Примери:

- Пушкин → Пушкину (винительний);
- Пушкин → Пушкино (родительний);
- Пушкин → Пушкине (дательний).

### 9.4.3. Неадаптирование имени

Неадаптирование имени сохраняют исходное написание,
включая латиницу, диакритические знаки и регистр.

Они не проходят орфографическую нормализацию Русидо.

По умолчанию неадаптированое имен несклоняемо.
Если требуется склонение, словарная запись должна
указивать режим склонения.

При регулярном склонении окончание отделяется
от исходного написания дефисом.

Пример:

- Smith — именительний;
- Smith-у — винительний;
- Smith-о — родительний;
- Smith-е — дательний.

### 9.4.4. Составние имени

Составное имен по умолчанию склоняется по последний
изменяемому компоненту.

Если требуется иное склонение, он указивается
в словаре.

Дефис внутри официального написания имено
не считается автоматически границей морфем.

### 9.4.5. Словарние свойства

Для каждого имено собственая словарная запись
может содержать:

- режим записи: `adapted` / `external`;
- режим склонения: `regular` / `indeclinable`;
- основу;
- границу изменяемого компонента;
- исключительную форму, если он необходима.

Если режим склонения не указан для внешнего имено,
он считается несклоняемим.

## 9.5. Сложний слови

Сложний слови образуются соединением два
или более корней.

При наличии соединительной морфеми он
указивается между компонентами.

Сложний слови должни иметь словарную запись
с указанием состава компонентов.

Наличие нескольких известий корней внутри слови
не является достаточним основанием для его
автоматического признания сложний.

## 9.6. Морфемний анализ

Морфемний анализ виполняется в следующий порядке:

1. Проверка полного совпадения с словарной лемой.
2. Поиск зарегистрированой производной леми.
3. Проверка допустимих приставок и производящих основ.
4. Проверка суфиксов и соединительних морфем.
5. Проверка словоизменительних показателей.
6. Возврат всех допустимих разборов при неоднозначности.

Валидатор не должен удалять приставку только
на основании совпадения начальной последовательности
символов с елементом списка приставок.

Если производящая лема или словообразовательная
модель не подтверждена словаре, автоматический
морфемний разбор не виполняется.

Илюстративний алгоритм:

```python
def analyze_word(word, lexicon, prefixes):
    """
    Анализирует слову по словаре.
    Не считает любую начальную последовательность
    приставкой без подтверждения производящей леми.
    """

    # 1. Прямое совпадение с словарной лемой
    if word in lexicon:
        return lexicon[word]

    # 2. Поиск возможной приставки
    candidates = []

    for prefix in prefixes:
        if not word.startswith(prefix):
            continue

        remainder = word[len(prefix):]

        # 3. Проверка производящей леми
        for lemma, entry in lexicon.items():
            if entry["stem"] == remainder[:-2]:
                candidates.append({
                    "word": word,
                    "prefix": prefix,
                    "base_lemma": lemma,
                    "base_stem": entry["stem"],
                })

    # 4. Неоднозначность не скривается
    if len(candidates) == 1:
        return candidates[0]

    if len(candidates) > 1:
        return {
            "status": "ambiguous",
            "candidates": candidates,
        }

    return {"status": "unknown"}
```

# 10. СВОДНАЯ ГРАМАТИКА

## Существительное

```
корен + числ + падеж
```

Числ:

```
∅ / -и
```

Падеж:

```
∅ / -у / -о / -е
```

## Прилагательное

```
корен + -ий
```

Не изменяется.

## Глагол

Инфинитив:

```
-ти
```

Настоящее:

```
1 ед. -м    1 мн. -ми
2 ед. -ш    2 мн. -тот
3 ед. -т    3 мн. -ни
```

Прошедшее:

```
ед. -л
мн. -ли
```

Будущее:

ЛИЧНАЯ ФОРМА `БУДТИ` + ИНФИНИТИВ ОСНОВНОГО ГЛАГОЛА.

```
будеми, будеш, будет,
будеми, будете, будени
```

Условное:

```
би + прошедшее
```

Пасив:

```
се + глагол
```

## Синтаксис

```
SVO
```

Причастия:

```
кторий + глагол
```

## Числ

Только:

```
единственое
множественое
```

**Двойственое числ отсутствует.**
