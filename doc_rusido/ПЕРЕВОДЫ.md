# doc_rusido — переводи документов проекта на Русидо

Здесь лежат переводи на Русидо всех документов репозитория:

| Файл | Источник |
|---|---|
| `README.md` | `README.md` — концепция комплекса |
| `Rusido.md` | `Rusido.md` — спецификация языка |
| `proposal.md` | `proposal.md` — критика спецификации и предложения |
| `plan.md` | `plan.md` — дорожная карта |
| `AGENTS.md` | `AGENTS.md` — указания для ИИ-агентов |
| `TODO.md` | `TODO.md` — список проблем |

Перевод выполнен автоматически собственним переводчиком проекта
(`rusido.cli translate`, NLP-бэкенд pymorphy3). Это не художественний
перевод: качество — уровень текущего MVP, известние ограничения:

- неизвестние лексикону слова проходят только орфографическую нормализацию
  (например, «открытых» → «откритих»);
- синкретизм падежей разрешается первой гипотезой pymorphy3
  (например, «книги» → «книго»);
- чередования основ не применяются («люблю» → «люблем», а не «люблем»);
- структура Markdown, код и имена файлов не переводятся.

При изменении исходних документов обновляйте переводи той же командой:

```
PYTHONPATH=src python3 -m rusido.cli translate -i TODO.md -o doc_rusido/TODO.md
```

Эти переводи — одновременно и тестовий корпус для оценки качества
переводчика (см. README §4.6, §11.5).
