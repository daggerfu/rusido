## Замечания по NLP-интеграции (pymorphy3)

- [x] **Синкретизм падежей снят контекстним вибором гипотези pymorphy3** (D-024): приоритет леми из лексикона → контекстной гипотези падежа (предлог, SVO-обьект, подлежащее) → частотной оценки. «книги» → «книги» (они. мн.) / «книгиу» (вин. мн. после глагола), «дверу» → «двер» / «дверу». Дополнено 2026-11-17: предикат «нет» управляет родительним (§8.4, «У мне нет книго»), дательние предлоги требуют косвеной форми местоимения (§5.2, «у ним» → «у ним»); регресионие тести в `test_translator.py`. Дополнено 2026-11-17: непереходние глаголи (`tran`/`intr` из pymorphy3) болший не порождают винительний обьект (D-026, «я идем дом» → «я идеми дом»). Остаток: частотний словар для редкой омонимии.
- [x] **Будущее связки «будет»**: `будти` получило два функции — вспомогательную (`будет читати`) и связочную (`Он будет студент`); личная форма самостоятельна, руский падеж именого сказуемого не переносится, обладание согласуется с обьекте по числе (`будет`/`будени`), `есет` инвариантно (D-025, §7.4/§8.3).
