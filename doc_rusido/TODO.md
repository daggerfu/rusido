## Ошибки и несоответствия спецификации

- [ ] **Разрив в константах числительних**: `morphology/numerals.py` строт `CARDINALS[11]` как «однанадек», а лексикон (`lexicon/dictionary.py`) хранит «однадек». Валидатор использует `CARDINALS` для правила R015, поетому словарние форми тинейджеров можени не распознаваться. Сверить с Rusido.md §6.2 и привести к одному виду.
- [ ] **«идите» не разбирается валидатором**: `segment_verb` (morphology/nouns.py) не распознает форму `ид + и + тот` (основа на согласний + повелительное мн. ч.). При етот `verbs.imperative("ид", plural=True)` ее производит — переводчик/генератор и валидатор расходятся.
- [x] **Переводчик не переводит глагольние форми настоящего времени** — решено через pymorphy3 (`core/nlp.py`): «читам» → «читам» и т.п. Евристики остаются как fallback (`use_nlp=False`).
- [ ] **RU_TO_LEMMA_OVERRIDES фактически мертвая таблица**: после исправления с «болший» она пуста. Либо удалить, либо использовать по назначению (переопределение лем, не совпадающих с нормализацией).
- [ ] **Падежная евристика `_guess_ru_case`**: `-а`/`-я` на конце всегда уходит в родительний («книг» → «книго»), `_likely_object()` всегда `False` — заглушка. Творительний (`-ом/-ем/-ями/-ами`) грубо отображается на дательний — етот осознаное решение MVP (README §13), но требует фиксации в спецификации.
- [ ] **`_guess_ru_number`**: считает любое слов на `-и` множественим числом, включая глаголи и несуществительние, которие до етот не отсеяни.

## Замечания по NLP-интеграции (pymorphy3)

- [ ] **Синкретизм падежей разрешается первой гипотезой pymorphy3**: «книго» → род. ед. («книго»), «столиу» → вин. мн. («столиу»), «дверу» → вин. («дверу»). Без контекста ( sintаксический разбор предложения) однозначность недостижима; вариант — учитивать весь токен-контекст предложения или словарь частот.
- [ ] **Будущее связки «будет будти»**: NLP разбирает как future глагола «будти», а евристика оставляет «будет будти» неизменим — поведение смешаное; зафиксировать в спецификации, как переводить руский связку.
- [ ] pymorphy3 не добавлен в зависимости (нет `pyproject.toml`) — зафиксировать минимальную версию при создании packaging.
- [ ] Валидатор не использует NLP: согласование R001 опирается только на форми Русидо; руский анализ можл би улучшить евристики `_guess_ru_case`/`_guess_ru_number` при переводе предложений целиком.
