# 1. ОБЩАЯ КОНЦЕПЦИЯ

**Русидо** — искусственный язык на русской лексической базе с регулярной агглютинативной грамматикой.

Название: **Рус + идо** — «упорядоченный русский».

Цель:

> Сохранить узнаваемость русского слова, но убрать исключения, нерегулярность и сложность грамматики.

Принципы:

1. Одно правило → один результат.
2. Нет грамматических исключений.
3. Русские корни сохраняются.
4. Грамматика полностью регулярна.
5. Каждое грамматическое значение выражается отдельной морфемой.

Тип языка:

- агглютинативный;
- синтетический в словоизменении;
- аналитический в сложных конструкциях.

## 1.1. Три слоя письменного текста

Русидо определяется не только грамматикой слов, но и правилами
обработки текста, который не является обычным русским словом.
Выделяются три слоя:

1. **Внутренний язык** — лексика, морфология, синтаксис.
2. **Орфографическая оболочка** — алфавит, регистр, пунктуация,
   правила записи (§2.7—2.8, §6.7).
3. **Внешние токены** — имена, оригинальные названия, аббревиатуры,
   неадаптированные заимствования и цифровые выражения
   (§2.9, §9.3).

Не каждый фрагмент входного текста проходит через морфологический
анализатор: внешние токены распознаются на уровне оболочки и
сохраняют исходное написание.

# 2. АЛФАВИТ, ФОНЕТИКА, ОРФОГРАФИЯ

## 2.1. Алфавит

29 букв:

```
А Б В Г Д Е Ж З И Й К Л М Н О П Р С Т У Ф Х Ц Ч Ш Щ Ь Ю Я
```

Строчные:

```
а б в г д е ж з и й к л м н о п р с т у ф х ц ч ш щ ь ю я
```

## 2.2. Отсутствующие буквы

| Русская | Замена |
|---|---|
| ё | е |
| ы | и |
| э | е |
| ъ | ь |

Примеры:

```
ёлка → елка
чёрный → черний
это → ето
объект → обьект
```

Небольшой закрытый набор служебных слов имеет уникальные формы, не выводимые
правилами замены, и фиксируется словарём:

```
что → што, чтобы → штоби, который → кторий, ещё → ешо
```

## 2.3. Гласные

```
а е и о у ю я
```

Произношение:

| Буква | Звук |
|---|---|
| а | [а] |
| о | [о] |
| у | [у] |
| и | [и] |
| е | [э] / [йэ] |
| я | [а] с мягкостью / [йа] |
| ю | [у] с мягкостью / [йу] |

Редукции нет: `вода`, `молоко` читаются как написаны.

## 2.4. Согласные

```
б в г д ж з й к л м н п р с т ф х ц ч ш щ
```

Мягкость — перед `е, и, я, ю, ь`.

`ь` имеет два регулярных употребления:

1. **Мягкость** — в конце основы (дверь → двер-) и перед гласными внутри
   основы (армия, письмо).
2. **Замена запрещённого `ъ`** — на месте русского твёрдого знака; такой `ь`
   НЕ смягчает согласную и читается как разделительный:

```
объект → обьект [тв. т], подъезд → подьезд, съезд → сьезд
```

`ъ` запрещён.

### Конечный мягкий знак

Конечный `ь` исходного русского слова не входит в основу
Русидо и удаляется при нормализации.

После удаления `ь` полученная основа используется без изменений
при присоединении падежных окончаний, глагольных окончаний
и словообразовательных суффиксов.

Сохранение `ь` перед аффиксами не допускается.
Вставка дополнительного `ь` между основой и аффиксом
также не допускается.

Примеры:

```
дверь → двер-
дверь + -е → двере
дверь + -ие → дверие
тетрадь → тетрад-
тетрадь + -е → тетраде
тетрадь + -ий → тетрадий
```

## 2.5. Ударение

Ударение не является различительным признаком и не регламентируется:
оно сохраняется от исходного русского слова (книга́, маши́на, рабо́та).
При словоизменении ударение НЕ смещается — оно остаётся на том же слоге
основы, даже если добавленные аффиксы меняют счёт слогов:

```
сто́л → сто́лу, сто́лиу (ударение на основе, аффиксы безударные)
```

Для односложных слов ударение падает на единственный слог.

## 2.6. Удвоенные согласные

Удвоенные согласные запрещены. В любом слове две одинаковые согласные подряд
сокращаются до одной:

```
агглютинативный → аглютинативний
русский → руский
класс → клас
```

Правило применяется после замены запрещённых букв (§2.2) и охватывает всё слово,
включая основу и аффиксы. Оно не применяется к внешним токенам (§2.9, §9.3).

## 2.7. Регистр

Регистр букв не изменяет лексическое значение,
грамматическую категорию или морфологическую форму слова.

Русидо различает прописные и строчные буквы. Регистр не меняет
значение слова, его произношение или грамматические свойства.

### Стандартное написание

В стандартном режиме:

- первое слово предложения начинается с заглавной буквы;
- имена собственные начинаются с заглавной буквы;
- аббревиатуры сохраняют установленный регистр;
- обычные слова пишутся строчными буквами.

### Нестандартный регистр

Полностью прописное или строчное написание допускается
как стилистическое отклонение. Названия и заголовки могут
использовать произвольный регистр.

```
Я читам.
Я ЧИТАМ.
я читам.
```

При лексической нормализации регистр учитывается
только как орфографическое оформление. Аббревиатуры
и внешние токены не подвергаются автоматической нормализации.

Регистр не является основанием для отклонения текста
грамматическим анализатором. Орфографический валидатор
может выдавать предупреждения о несоблюдении стандартного
регистра.

## 2.8. Пунктуация

### 2.8.1. Общий принцип

Русидо использует русскую систему пунктуации. Знаки препинания
выполняют синтаксическую и просодическую функцию: отделяют
предложения, указывают паузы, выделяют прямую речь и цитаты.

Знаки препинания не являются морфемами, не входят в состав
слова и не изменяют его форму. Пунктуация не влияет
на морфологическую структуру слова.

### 2.8.2. Инвентарь знаков

```
. , ; : ? ! … — - « » " " ( ) [ ] /
```

Дефис `-` используется внутри лексического токена (§2.12.1).
Тире `—` отделяется пробелами и оформляет паузу или реплику.
Основные кавычки — `« »`; `" "` допускаются во вложенных
цитатах и внутри внешних текстов.

### 2.8.3. Конец предложения

- `.` — конец повествовательного предложения;
- `?` — вопрос;
- `!` — восклицание;
- `…` — незавершённость или пауза.

Пробел ставится после знака препинания, но не перед ним.
Согласование подлежащего и сказуемого проверяется
в пределах одного предложения.

```
Я читам.
Ти читаш?
Он читат!
Я читам …
```

### 2.8.4. Запятая, точка с запятой, двоеточие и тире

- запятая разделяет однородные члены, вводные слова,
  обращения и части сложного предложения;
- точка с запятой разделяет части, внутри которых
  уже есть запятые;
- двоеточие вводит пояснение, перечисление или прямую речь;
- тире оформляет паузу, уточнение, противопоставление
  и реплики диалога.

```
Я читам: книгу.
Я читам — книгу.
Я читам (книгу).
```

### 2.8.5. Прямая речь, цитаты и диалог

Прямая речь выделяется кавычками `« »`. Слова автора
присоединяются через двоеточие или тире:

```
Он говорил: «Я читам».
«Ти читаш?» — он читат.
```

Реплики диалога начинаются с тире:

```
— Я читам.
— Ти читаш?
```

Вложенная цитата заключается в `" "`. Пунктуация внутри
цитат и внешних текстов сохраняется (§1.1, §9.3).

### 2.8.6. Скобки и косая черта

Круглые скобки выделяют пояснение, квадратные — вставку
в цитате. Косая черта разделяет варианты или части
неадаптированного написания.

### 2.8.7. Дефис и тире

Дефис соединяет компоненты одного слова и не отделяется
пробелами (`тук-тук`, §2.12.1). Тире отделяется пробелами
и соединяет части текста, но не слова.

## 2.9. Имена собственные

Имена собственные подразделяются на два типа:

1. Адаптированные — оформляются по орфографическим
   и грамматическим правилам Русидо.
2. Оригинальные — сохраняют исходное написание,
   регистр и диакритические знаки.

К оригинальным именам не применяются:
- замена букв (§2.2);
- сокращение удвоенных согласных (§2.6);
- автоматическая транслитерация.

Оригинальные имена могут получать грамматические
показатели через дефис:

Анна-у
Анна-о
Анна-е

В составе полного имени показатель присоединяется
к последнему компоненту:

Иван Петров-у.

## 2.10. Междометия и звукоподражания

### 2.10.1. Определение

Междометия и звукоподражания образуют отдельный
лексико-грамматический класс — экспрессивные слова.

Они не относятся к существительным, глаголам,
прилагательным или служебным словам.

### 2.10.2. Подклассы

Различаются:

1. Междометия — выражают эмоции, реакции,
   призывы и волеизъявление.
2. Звукоподражания — воспроизводят звуки,
   шумы и голоса живых существ.

Примеры междометий: `О`, `Ай`, `Ура`, `Ау`.
К междометиям относятся также приветствия (`привет`,
`здравствуй`, `здравствуйте`), зарегистрированные
в лексиконе (§9.3).

Примеры звукоподражаний: `Мяу`, `Гав`, `Бум`, `Тук-тук`.

### 2.10.3. Грамматические свойства

Экспрессивные слова:

- не имеют грамматического рода;
- не изменяются по числу;
- не склоняются;
- не спрягаются;
- не согласуются с другими словами;
- не требуют падежного управления.

Экспрессивное слово может самостоятельно
образовывать высказывание или входить в состав
предложения как отдельный компонент.

### 2.10.4. Орфография

Допускаются:

- повторение: `ха-ха`, `тук-тук`;
- дефисные сочетания: `динь-дон`;
- удлинение букв как экспрессивный приём: `Ааа`.

Удлинение букв не является грамматическим
словоизменением. Пунктуация определяется общими
правилами (§2.8).

## 2.11. Аббревиатуры

### 2.11.1. Определение

Аббревиатуры являются отдельным лексическим классом.
Они обозначают сокращённые наименования организаций,
понятий, учреждений и других объектов.

### 2.11.2. Написание

Аббревиатуры сохраняют установленное написание,
включая регистр букв.

Аббревиатуры не проходят автоматическую
орфографическую нормализацию Русидо.

Примеры:

```
СССР
ООН
ИИ
МГУ
НАТО
```

### 2.11.3. Произношение

Произношение аббревиатуры определяется словарной записью.

Различаются:

1. Буквенное чтение — произношение названий букв.
2. Словесное чтение — произношение как обычного слова.

Написание аббревиатуры не определяет автоматически
способ её произношения.

### 2.11.4. Грамматическое поведение

Аббревиатуры по умолчанию являются несклоняемыми
и не изменяются по числу.

Если требуется словоизменение, оно должно быть
явно определено словарной записью.

## 2.12. Дефисные и апострофные написания

### 2.12.1. Дефис

Дефис `-` допускается внутри одного лексического токена.

Он используется:

- в дефисных словах;
- в составных именах собственных (§9.4.4);
- в звукоподражаниях (§2.10);
- в словарно закреплённых составных служебных словах;
- при отделении окончания от неадаптированной основы,
  если такое склонение разрешено словарём (§9.4.3).

Дефис сам по себе не обозначает границу
между отдельными словами.

Примеры:

```
по-русски
Йошкар-Ола
тук-тук
```

### 2.12.2. Апостроф

Апострофы `'` и `’` не входят в алфавит
и стандартную орфографию Русидо.

Они допускаются только внутри неадаптированных
внешних токенов, если присутствуют в исходном
написании имени или заимствования (§9.3, §9.4).

Внешние токены сохраняют исходное написание
и не проходят автоматическую нормализацию.

Пример: `O'Connor`.

Апостроф не используется как стандартный
морфологический разделитель.

### 2.12.3. Токенизация

Токенизатор различает:

1. Слова и составные лексические токены.
2. Пробелы между словами.
3. Пунктуационные знаки.
4. Внешние токены.

Дефис внутри слова не создаёт границу
между отдельными лексическими токенами.

Апостроф внутри внешнего токена не создаёт
границу между токенами.

Пунктуация отделяется от слов, если она
не входит в зарегистрированное внешнее написание.

### 2.12.4. Словарная обработка

Дефисные слова должны иметь словарную запись
или выводиться по явно установленному правилу.

Неадаптированные имена и заимствования
с апострофом сохраняются без изменений.

Неизвестные последовательности с апострофом
не должны автоматически преобразовываться
в обычные слова Русидо.

# 3. СУЩЕСТВИТЕЛЬНЫЕ

## 3.1. Структура

```
КОРЕНЬ + ЧИСЛО + ПАДЕЖ
```

Основа — русский корень без окончания:

| Русский | Основа |
|---|---|
| стол | стол |
| вода | вод |
| книга | книг |
| дверь | двер |
| армия | арми |

## 3.2. Род и обозначение пола

**Принцип.** Русидо — язык без грамматического рода, но не без средств
лексического обозначения пола.

Отсутствие грамматического рода означает, что:

- местоимение `он` универсально для 3-го лица единственного числа
  (русские `она`, `оно` переводятся как `он`, §5.1);
- прилагательные неизменяемы и не согласуются с именем (§4);
- глагольные формы не различают род: прошедшее время выражает только число
  (§7.3);
- пол различается лексически — суффиксами `-ец` / `-ица`, `-ник` / `-ница`
  в названиях профессий и ролей (§9.2).

Суффиксы `-ец`/`-ица` — словообразовательные, а не согласовательные.
Они позволяют отдельно назвать мужчину и женщину, но не требуют изменения
других слов в предложении: `учителец дал книгу` и `учителица дал книгу`
одинаково грамматичны.

Пример:

```
учитель → учителец / учителица
```

## 3.3. Число

Только два числа:

| Число | Окончание |
|---|---|
| Единственное | ∅ |
| Множественное | -и |

Примеры:

```
стол → столи
книг → книги
дом → доми
```

**Двойственного числа нет.** Для двух предметов используется множественное число:

```
два столи
два собаки
```

## 3.4. Падежи

Четыре падежа:

| Падеж | Значение | Окончание |
|---|---|---|
| Именительный | субъект | ∅ |
| Винительный | объект | -у |
| Родительный | принадлежность | -о |
| Дательный | адресат | -е |

## 3.5. Парадигма

Основа `стол`:

| Падеж | Ед. ч. | Мн. ч. |
|---|---|---|
| Им. | стол | столи |
| Вин. | столу | столиу |
| Род. | столо | столио |
| Дат. | столе | столие |

Основа `книг`:

| Падеж | Ед. ч. | Мн. ч. |
|---|---|---|
| Им. | книг | книги |
| Вин. | книгу | книгиу |
| Род. | книго | книгио |
| Дат. | книге | книгие |

Примеры:

```
Я видем книгу.
У мне нет книго.
Я давам книгу брате.
```

## 3.6. Имена собственные в падежах

Адаптированные имена собственные склоняются
по общей модели существительных.

Оригинальные имена собственные сохраняют
исходную форму и получают падежный показатель
через дефис:

Именительный: Анна
Винительный: Анна-у
Родительный: Анна-о
Дательный: Анна-е

Множественное число личных имён не образуется
автоматически.

# 4. ПРИЛАГАТЕЛЬНЫЕ

Прилагательные **не изменяются** по роду, числу и падежу.

Структура:

```
ОСНОВА + -ий
```

Примеры:

```
красивий
новий
болший
синий
```

Прилагательное всегда перед существительным:

```
красивий дом
новий книги
в болший доме
```

Степени сравнения:

```
более красивий
самий красивий
```

Кратких форм нет:

```
дом красивий
```

# 5. МЕСТОИМЕНИЯ

## 5.1. Личные

| Лицо | Ед. ч. | Мн. ч. |
|---|---|---|
| 1 | я | ми |
| 2 | ти | ви |
| 3 | он | они |

Двойственного числа у местоимений нет.

Местоимение `он` универсально и безродово: русские `она`, `оно` переводятся
как `он` (она дала книгу → он дал книгу). Отдельных форм `она`/`оно` в Русидо нет.

## 5.2. Косвенные формы

Косвенные формы личных местоимений:

| Именительная форма | Косвенная форма |
|---|---|
| я | мне |
| ти | тебе |
| он | нему |
| ми | нам |
| ви | вам |
| они | ним |

Косвенная форма используется после предлогов и в других
позициях, требующих косвенного местоимения.

Примеры:

```
Я идем к тебе.
Он идет к нему.
Он дал книгу мне.
У мне ест книга.
С ним я иду.
```

## 5.3. Притяжательные

Не изменяются:

```
мой, твой, его, наш, ваш, их
```

Примеры:

```
мой дом
твой книга
наш город
```

Форма `его` — притяжательное определение: она обозначает
принадлежность третьему лицу и не заменяет косвенную форму `нему`.

```
его книга
его дом
я вижу его книгу
```

Различаем:

- `нему` — косвенная форма личного местоимения;
- `его` — притяжательная форма.

## 5.4. Указательные

```
етот, тот, такой
```

## 5.5. Вопросительные и относительные слова

```
кто, што, какий, кторий, где, куда, откуда, когда, почему, как, сколько
```

`какий` — вопросительное местоименное слово. Используется для запроса
признака, типа или выбора объекта. Не изменяется по роду и числу.

Примеры:

```
Какий книга ти читаш?
Какий дом ти хотел?
Какий человек пришел?
```

`кторий` — неизменяемый относительный маркер. Вводит придаточное
определительное предложение и связывает его с существительным
в главной части.

Примеры:

```
Человек, кторий читат.
Книга, кторий лежат.
Доми, кторий стоят.
```

`какий` и `кторий` не являются взаимозаменяемыми:

- `какий` задаёт вопрос о признаке или разновидности;
- `кторий` вводит относительное придаточное.

# 6. ЧИСЛИТЕЛЬНЫЕ

Числительные не изменяются.

## 6.1. 0–10

| Число | Русидо |
|---|---|
| 0 | нол |
| 1 | одн |
| 2 | два |
| 3 | три |
| 4 | четир |
| 5 | пят |
| 6 | шест |
| 7 | сем |
| 8 | восем |
| 9 | девят |
| 10 | десят |

## 6.2. 11–19

Числа 11–19 образуются присоединением суффикса `-надек`
к основе числительного от 1 до 9.

```
одн + надек = одннадек → однадек
два + надек = дванадек
три + надек = тринадек
четир + надек = четирнадек
пят + надек = пятнадек
шест + надек = шестнадек
сем + надек = семнадек
восем + надек = восемнадек
девят + надек = девятнадек
```

После присоединения суффиксов применяется правило
устранения удвоенных согласных (§2.6).

## 6.3. Десятки

```
двадек, тридек, четирдек, пятдек,
шестдек, семдек, восемдек, девятдек
```

## 6.4. Сотни и тысячи

Сотни и тысячи образуются композиционно.

Сотни:

```
100 = сто
200–900 = основа числительного (2–9) + сто
```

Тысячи:

```
1000–9000 = основа числительного (1–9) + тис
```

При соединении основы и разрядного показателя
действует правило устранения удвоенных согласных (§2.6).

Примеры:

```
600 = шест + сто = шестсто
700 = сем + сто = семсто
5000 = пят + тис = пятис
6000 = шест + тис = шестис
7000 = сем + тис = семтис
```

Составные числа образуются перечислением ненулевых
разрядов через пробел в порядке убывания:

```
ТЫСЯЧИ + СОТНИ + ДЕСЯТКИ + ЕДИНИЦЫ
```

Нулевые разряды пропускаются.

Примеры:

```
21 = двадек одн
125 = сто двадек пят
600 = шестсто
1001 = однтис одн
2026 = дватис двадек шест
7650 = семтис шестсто пятдек
```

Система охватывает числа от 0 до 9999.
Числа за пределами этого диапазона записываются цифрами
до введения новых разрядных показателей.

## 6.5. Согласование

| Значение | Существительное |
|---|---|
| Ровно 1 | единственное |
| 0 и 2 или больше | множественное |

Согласование определяется полным числовым значением,
а не последним компонентом составного числительного.

Примеры:

```
одн стол
два столи
нол столи
двадек одн столи
сто одн столи
```

Если количество понятно, числительное можно опустить, но существительное остаётся во множественном числе:

```
столи = два стола и больше
```

## 6.6. Порядковые

Суффикс `-им`:

```
одним, дваим, триим, четирим
```

В составном числительном `-им` присоединяется к последнему компоненту:

```
сто двадек пят → сто двадек пятим   (125-й)
двадек три → двадек триим           (23-й)
```

## 6.7. Запись чисел цифрами

Арабские цифры 0–9 разрешены.

Число, записанное цифрами, является полноценным
числовым выражением и не требует преобразования
в словесную форму.

Примеры:

```
2026
3,14
-15
3/4
25%
1 000 000
17.11.2026
15:30
10–20
```

Для десятичных чисел используется запятая.
Для разделения разрядов используется пробел.

Дата и время рассматриваются как специальные
числовые форматы, а не как обычные составные
количественные числительные.

Согласование числовой записи:

- значение ровно 1 — единственное число;
- остальные количественные значения — множественное число.

Примеры:

```
0 столи
1 стол
2 столи
21 столи
1,0 стол
1,5 столи
```

# 7. ГЛАГОЛЫ

Глагольная система полностью регулярна. Спряжений и исключений нет.

## 7.1. Основа глагола

Каждая глагольная лексема имеет явно определённую
инфинитивную основу. По умолчанию она определяется удалением
окончания `-ти`.

Например:

```
жити → жи-
любити → люби-
читати → чита-
писати → писа-
прочитати → прочита-
```

Приставки, входящие в состав лексемы, являются частью
основы и не добавляются на этапе спряжения.

Инфинитив образуется по модели `ОСНОВА + -ти`:

```
читати, делати, любити, ити, говорити
```

Вспомогательный глагол будущего времени:

```
будти → основа буд-.
```

Глагол `будти` является полноценной глагольной лексемой
и подчиняется общим правилам спряжения. Специальных
исключений для него нет.

Если глагол требует чередования, основы фиксируются словарём —
см. §7.1.1.

### 7.1.1. Алломорфы глагольной основы

По умолчанию каждая глагольная лексема имеет одну основу,
используемую во всех формах. Чередование согласных и гласных
внутри основы автоматически не производится.

Если лексема имеет несколько основ (алломорфов), все они
должны быть явно перечислены в словаре с указанием условий
их употребления. Алломорфы — варианты одной лексической
основы; такое чередование не считается нерегулярным
спряжением, если распределение однозначно определено словарём.

Для каждого глагола словарь может содержать:

- инфинитивную основу;
- основу настоящего времени;
- основу прошедшего времени;
- основу повелительного наклонения.

По умолчанию все основы совпадают. Дополнительная основа
не может выводиться только из традиционной русской формы слова.

| Лемма | Основная основа | Дополнительная основа |
|---|---|---|
| писати | писа- | — |
| любити | люби- | — |

Алломорфы применяются только в тех грамматических позициях,
для которых они явно зарегистрированы. Если дополнительная
основа не указана, используется основная основа без изменений.

Пример:

Инфинитив: ити

| Форма | Основа |
|---|---|
| Инфинитив | и- |
| Настоящее | ид- |
| Прошедшее | ид- |
| Повелительное | ид- |

Образование форм:

```
ити
ид + е + м = идем
ид + е + л = идел
ид + и = иди
```

Будущее время образуется с инфинитивом:
`будем ити`.

## 7.2. Настоящее время

Окончания:

| Лицо | Ед. ч. | Мн. ч. |
|---|---|---|
| 1 | -м | -ми |
| 2 | -ш | -те |
| 3 | -т | -ни |

Пример `читати`:

| Лицо | Форма |
|---|---|
| я | читам |
| ти | читаш |
| он | читат |
| ми | читами |
| ви | читате |
| они | читани |

Лексема `ести` (принимать пищу) имеет основу `ес-`.
Она спрягается по общему правилу для основ
на согласную с соединительной гласной `-е-`.

Парадигма:

| Лицо | Ед. ч. | Мн. ч. |
|---|---|---|
| 1 | есем | есеми |
| 2 | есеш | есете |
| 3 | есет | есени |

Форма `ест` не является формой глагола `ести`.

Парадигма вспомогательного глагола `будти`:

| Лицо | Форма |
|---|---|
| я | будем |
| ти | будеш |
| он | будет |
| ми | будеми |
| ви | будете |
| они | будени |

Основа `буд-` оканчивается на согласную, поэтому
перед личными окончаниями вставляется соединительная
гласная `-е-`.

Если основа на согласный, вставляется `-е-`:

`ити` → основа настоящего времени `ид-` (§7.1.1):

| Лицо | Форма |
|---|---|
| я | идем |
| ти | идеш |
| он | идет |
| ми | идеми |
| ви | идете |
| они | идени |

## 7.3. Прошедшее время

| Число | Окончание |
|---|---|
| Единственное | -л |
| Множественное | -ли |

При основе на согласный вставляется соединительная `-е-` (как в §7.2):

```
ид + е + л = идел, мн. ч. идели
```

Примеры:

```
я читал
они читали
он идел
```

Вспомогательный глагол `будти` также образует
прошедшее время по общему правилу:

```
буд + е + л = будел
буд + е + ли = будели
```

**Двойственного числа нет:** для двух субъектов используется `-ли`.

## 7.4. Будущее время

Вспомогательный глагол будущего времени — `будти`.

- Лемма: `будти`.
- Основа: `буд-`.

Личные формы совпадают с формами настоящего времени (§7.2):

| Лицо | Единственное число | Множественное число |
|---|---|---|
| 1-е | будем | будеми |
| 2-е | будеш | будете |
| 3-е | будет | будени |

Будущее время образуется сочетанием личной формы `будти`
с инфинитивом смыслового глагола.

Глагол `будти` используется в двух конструкциях:

1. Как вспомогательный глагол будущего времени:
   личная форма `будти` + инфинитив основного глагола.
2. Как связочный глагол будущего времени:
   субъект + личная форма `будти` + именная
   или качественная часть сказуемого.

В первом случае основной глагол сохраняет инфинитив.
Во втором случае инфинитив отсутствует.

Примеры вспомогательной конструкции:

```
я будем читати
ти будеш читати
он будет читати
ми будеми читати
ви будете читати
они будени читати
```

Примеры связочной конструкции:

```
Я будем студент.
Он будет врач.
Дом будет красивий.
```

В связочной конструкции `будти` согласуется
с субъектом по лицу и числу.

Глагол `будти` не является исключением из общей системы
спряжения. Его формы образуются по правилам §7.2.

## 7.5. Повелительное наклонение

Повелительное наклонение образуется от основы инфинитива
или от явно указанного алломорфа:

- основа на согласный: `+ и`;
- основа на гласный: `+ й`.

Чередование согласных при образовании повелительного
наклонения не производится, если оно не указано
в словаре как отдельный алломорф.

Примеры:

```
ити → иди (ид + и)
писати → писай
читати → читай
любити → любий
```

Формы типа `пиши` не образуются из `писати` автоматически.
Для их использования необходимо отдельно зарегистрировать
соответствующий алломорф основы.

Множественное число: `+ те`

```
идите, читайте, делайте
```

## 7.6. Условное наклонение

```
би + прошедшее время
```

Примеры:

```
Я би читал.
Они би пришели.
```

## 7.7. Отрицание

```
не + глагол
```

```
Я не читам.
Он не идет.
Они не работани.
```

## 7.8. Страдательный залог

Каноническая пассивная конструкция:

```
объект + се + глагол
```

Агент действия может быть указан необязательной
предложной группой:

```
од + существительное в родительном падеже
```

Примеры:

```
Книга се читат.
Дом се строт.
Книга се писал.
Книга се писал од авторо.
```

Предложная группа с `од` не образует отдельного типа
пассивной конструкции. Она только обозначает агента.

## 7.9. Безличные конструкции

```
ну + состояние + косвенное местоимение
```

```
Ну холодно мне.
Ну плохо нему.
```

## 7.10. Вид

Обязательного вида нет. Вид передаётся лексически: служебными глаголами
`начати` (начать) и `продолжати` (продолжать), а также частицей `уже`.

Вид не изменяет правила образования глагольных форм.
Если две лексемы образуют видовую пару, их связь
фиксируется в словаре:

```
читати — несовершенный вид
прочитати — совершенный вид
```

Приставка, входящая в состав лексемы, включается
в её основу:

```
читати → чита-
прочитати → прочита-
```

Время и лицо образуются от полной основы лексемы
по общим правилам спряжения.

Примеры:

```
Я продолжам читати.
Я уже прочитал книгу.
Я начам работати.
```

## 7.11. Причастия и деепричастия

Специальных форм нет. Используются конструкции с `кторий`, `когда`, `потому што`.

Относительный маркер `кторий` неизменяем. Он не согласуется
с определяемым существительным по роду, числу или падежу.
Глагол внутри относительного придаточного оформляется
по обычным правилам спряжения.

Примеры:

```
человек, кторий читат
человек, кторий прочитал книгу
книга, кторий се писал
книга, кторий лежат
доми, кторий стоят
человеки, кторий работани
```

## 8.1. Базовый порядок

```

```

Пример:

```

```

Порядок может меняться для выделения, но SVO предпочтителен.

## 8.2. Именная группа

```

```

```

новий книги
```

Несколько прилагательных:

```

```

## 8.3. Владение

Конструкция наличия:

```
у + обладатель (косвенная форма) + ест + объект
```

Предикатор `ест` обозначает существование или наличие объекта.
Он является инвариантным служебным предикатором,
а не формой глагола `ести`. Не изменяется по лицам,
числам и временам.

Конструкция:

```
у + обладатель (косвенная форма) + ест + объект (именительный падеж)
```

Примеры:

```
У мне ест книга.
У нему ест дом.
У ним ест собаки.
```

Объект при `ест` употребляется в именительном падеже.
`ест` не требует родительного падежа.

Не следует смешивать:

- `ест` — имеется, существует;
- `ести` — принимать пищу;
- `есет` — форма 3-го лица единственного числа глагола `ести`.

`ест` — неизменяемый экзистенциальный предикатор,
выражающий существование, наличие или обладание.

`ест` не является обычным спрягаемым глаголом.
Он:

- не имеет лица;
- не имеет числа;
- не согласуется с обладателем;
- не согласуется с объектом;
- не изменяется по родам;
- не принимает глагольных окончаний;
- не имеет инфинитива.

В конструкции обладания используется модель:

у + обладатель (дательный падеж) + ест + объект.

Примеры:

```
У мне ест книга.
У нему ест два собаки.
У ним ест новий дом.
```

В настоящем времени используется неизменяемый предикатор `ест`.

В будущем времени вместо `ест` используется личная форма `будти`.
Она согласуется с обладаемым объектом по числу:

- единственное число — форма 3-го лица единственного числа;
- множественное число — форма 3-го лица множественного числа.

Примеры:

```
У мне ест книга.
У мне будет книга.
У нему будет дом.
У ним будени собаки.
```

В конструкции обладания `ест` обязательно и не может опускаться
без изменения грамматической конструкции.

В именных и качественных сказуемых настоящего времени
связка отсутствует:

```
Я студент.
Дом красивий.
Он учитель.
```

Отсутствие связки в таких предложениях является
нормативной нулевой связкой, а не пропуском `ест`.

Временная парадигма `ест` в данной версии
не устанавливается. Прошедшее и будущее время
конструкции обладания требуют отдельного определения.

## 8.4. Отрицание

```
не + сказуемое
```

Отсутствие:

```
нет
```

После предикатора `нет` существительное ставится
в родительный падеж. Падежное окончание присоединяется
по общей модели склонения существительных.
Форма именительного падежа после `нет` не допускается.

Примеры:

```
У мне нет книго.
У нему нет домо.
```

Конструкция отсутствия:

```
у + обладатель (косвенная форма) + нет + объект в родительном падеже
```

При отрицании существования родительный падеж
используется независимо от числа объекта.

## 8.5. Вопросы

В вопросе без частиц порядок слов не меняется. С частицей `ли` глагол
может предшествовать подлежащему (единственное регулярное отклонение от SVO):

```
Ти читаш книгу?
Читаш ли ти книгу?   (VSO допустимо только с «ли»)
```

## 8.6. Предлоги

Предлоги не изменяются и стоят перед существительным.

Основные:

```
в, на, у, к, из, от, с, без, для, о, од, под, до
```

Управление в данной концепции унифицировано:

- статика: дательный — `в доме`, `на столе`;
- направление: винительный — `в дому`, `на столу`;
- адресат: дательный — `к брате`;
- источник: родительный — `из домо`, `от друго`;
- отсутствие: родительный — `без книго`;
- цель: родительный — `для друго`;
- тема: дательный — `о городе`;
- обладатель и близость: дательный — `у мне`, `у брате`;
- совместность: дательный — `с нему`, `с друге`;
- агент пассива и источник: родительный — `од авторо`, `од друго` (см. §7.8).

`од + родительный падеж` обозначает агента действия
в пассивной конструкции.

Русский творительный падеж в Русидо не выделяется: формы на `-ом/-ем/-ями/-ами`
передаются дательным окончанием `-е` (`с братом → с брате`, `под столом → под столе`).
Это постоянное правило версии 1.0, а не временная эвристика переводчика (D-013).

Примеры:

```
в доме
на столе
к брате
из домо
без книго
для друго
о городе
у мне
с нему
од авторо
```

# 9. СЛОВООБРАЗОВАНИЕ

Один аффикс — одно основное значение.

## 9.0. Общий порядок морфем

Морфемная структура производного слова:

```
ПРИСТАВКА + КОРЕНЬ + СУФФИКС + СЛОВОИЗМЕНИТЕЛЬНЫЙ ПОКАЗАТЕЛЬ
```

Необязательные морфемы могут отсутствовать.

Для глаголов:

```
ПРИСТАВКА + ГЛАГОЛЬНАЯ ОСНОВА + -ти
```

Приставки располагаются перед корнем. Суффиксы располагаются
после корня. Словоизменительные показатели располагаются
после словообразовательных морфем.

## 9.1. Приставки

Приставки образуют новые лексемы путём присоединения
к производящей основе.

Наличие начальной последовательности букв, совпадающей
с приставкой, само по себе не доказывает приставочного
происхождения слова.

Приставочное слово должно иметь:

- производящую лемму;
- зарегистрированную приставку;
- производную основу;
- при необходимости — словарное значение.

Автоматическое чередование корня при присоединении
приставки не допускается, если оно не описано
отдельным морфологическим правилом.

Список приставок:

```
в-/во- — внутрь
вы- — наружу
за- — начало / за предел
до- — завершение
пере- — повторение / изменение
про- — через / полностью
от- — удаление
под- — приближение / ниже
при- — прибытие / присоединение
раз- — разделение / усиление
с- — совместность / вниз
без- — отсутствие
```

Примеры:

```
войти, выйти, записати, дописати,
переписати, прочитати, отойти,
подойти, прийти, разделити,
сделати, бездом
```

```
-ник, -ница, -ец, -ица, -ист
```

Примеры:

```

```

Действие:

```

```

```

Абстрактные понятия:

```

```

```

```

Предметы и инструменты:

```
-ло, -ка, -ница, -ник
```

```
писало, тетрадка, сахарница, чайник
```

Уменьшение и увеличение:

```

```

```

## 9.3. Заимствования

### 9.3.1. Общий принцип

Заимствованные слова могут использоваться в двух режимах:

- адаптированном;
- неадаптированном.

По умолчанию новые заимствования адаптируются,
если их можно записать средствами алфавита Русидо.

### 9.3.2. Адаптированные заимствования

Адаптированные заимствования проходят общую
орфографическую нормализацию Русидо (§2.2, §2.4).

Применяются следующие правила:

- `ё → е`;
- `ы → и`;
- `э → е`;
- конечный `ь` удаляется;
- удвоенные согласные сокращаются до одной.

Дополнительный знак `ь` перед `е`, `ю`, `я`
не вставляется автоматически. Мягкость согласного
перед `е`, `ю`, `я` определяется правилами фонологии
Русидо.

После адаптации слово получает обычную
словарную основу и подчиняется общей морфологии.

Примеры:

```
класс → клас
компьютер → компьютер
менеджер → менеджер
туннель → тунел
кофе → кофе
пюре → пюре
ёлка → елка
```

### 9.3.3. Неадаптированные заимствования

Неадаптированные заимствования сохраняют исходное
написание, включая символы, отсутствующие в алфавите
Русидо.

Они рассматриваются как внешние неизменяемые токены
(§1.1) и не подвергаются автоматической нормализации.

По умолчанию такие слова не склоняются и не изменяются
по числу.

Если требуется регулярное изменение, словарь должен
содержать адаптированную форму или явное описание
морфологической модели.

Примеры:

```
software
deadline
machine learning
```

Для образования регулярных глагольных форм
заимствованный глагол должен иметь словарную
лемму, соответствующую §7.1.

### 9.3.4. Словарная запись

Словарная запись заимствования может содержать:

- исходное написание;
- адаптированное написание;
- режим: `adapted` / `external`;
- нормализованную основу;
- часть речи;
- модель словоизменения.

Если адаптированная форма не задана,
она определяется общими правилами нормализации.

## 9.4. Имена собственные

### 9.4.1. Общий принцип

Имена собственные являются частью лексики Русидо.
Они сохраняют свою идентичность, но подчиняются
правилам орфографии и грамматики Русидо.

Различаются два режима записи:

1. Адаптированное имя.
2. Неадаптированное имя.

### 9.4.2. Адаптированные имена

Адаптированные имена записываются буквами Русидо
и проходят стандартную орфографическую нормализацию.

К ним применяются общие правила:

- `ё → е`;
- `ы → и`;
- `э → е`;
- `ъ → ь`, затем удаление конечного `ь`
  в соответствии с §2.4;
- сокращение удвоенных согласных.

Адаптированные имена склоняются по общей системе
числа и падежа (§3).

Примеры:

- Пушкин → Пушкину (винительный);
- Пушкин → Пушкино (родительный);
- Пушкин → Пушкине (дательный).

### 9.4.3. Неадаптированные имена

Неадаптированные имена сохраняют исходное написание,
включая латиницу, диакритические знаки и регистр.

Они не проходят орфографическую нормализацию Русидо.

По умолчанию неадаптированное имя несклоняемо.
Если требуется склонение, словарная запись должна
указывать режим склонения.

При регулярном склонении окончание отделяется
от исходного написания дефисом.

Пример:

- Smith — именительный;
- Smith-у — винительный;
- Smith-о — родительный;
- Smith-е — дательный.

### 9.4.4. Составные имена

Составное имя по умолчанию склоняется по последнему
изменяемому компоненту.

Если требуется иное склонение, оно указывается
в словаре.

Дефис внутри официального написания имени
не считается автоматически границей морфем.

### 9.4.5. Словарные свойства

Для каждого имени собственная словарная запись
может содержать:

- режим записи: `adapted` / `external`;
- режим склонения: `regular` / `indeclinable`;
- основу;
- границу изменяемого компонента;
- исключительную форму, если она необходима.

Если режим склонения не указан для внешнего имени,
оно считается несклоняемым.

## 9.5. Сложные слова

Сложные слова образуются соединением двух
или более корней.

При наличии соединительной морфемы она
указывается между компонентами.

Сложные слова должны иметь словарную запись
с указанием состава компонентов.

Наличие нескольких известных корней внутри слова
не является достаточным основанием для его
автоматического признания сложным.

## 9.6. Морфемный анализ

Морфемный анализ выполняется в следующем порядке:

1. Проверка полного совпадения со словарной леммой.
2. Поиск зарегистрированной производной леммы.
3. Проверка допустимых приставок и производящих основ.
4. Проверка суффиксов и соединительных морфем.
5. Проверка словоизменительных показателей.
6. Возврат всех допустимых разборов при неоднозначности.

Валидатор не должен удалять приставку только
на основании совпадения начальной последовательности
символов с элементом списка приставок.

Если производящая лемма или словообразовательная
модель не подтверждена словарём, автоматический
морфемный разбор не выполняется.

Иллюстративный алгоритм:

```python
def analyze_word(word, lexicon, prefixes):
    """
    Анализирует слово по словарю.
    Не считает любую начальную последовательность
    приставкой без подтверждения производящей леммы.
    """

    # 1. Прямое совпадение со словарной леммой
    if word in lexicon:
        return lexicon[word]

    # 2. Поиск возможной приставки
    candidates = []

    for prefix in prefixes:
        if not word.startswith(prefix):
            continue

        remainder = word[len(prefix):]

        # 3. Проверка производящей леммы
        for lemma, entry in lexicon.items():
            if entry["stem"] == remainder[:-2]:
                candidates.append({
                    "word": word,
                    "prefix": prefix,
                    "base_lemma": lemma,
                    "base_stem": entry["stem"],
                })

    # 4. Неоднозначность не скрывается
    if len(candidates) == 1:
        return candidates[0]

    if len(candidates) > 1:
        return {
            "status": "ambiguous",
            "candidates": candidates,
        }

    return {"status": "unknown"}
```

# 10. СВОДНАЯ ГРАММАТИКА

## Существительное

```
корень + число + падеж
```

Число:

```
∅ / -и
```

Падеж:

```
∅ / -у / -о / -е
```

## Прилагательное

```
корень + -ий
```

Не изменяется.

## Глагол

Инфинитив:

```
-ти
```

Настоящее:

```
1 ед. -м    1 мн. -ми
2 ед. -ш    2 мн. -те
3 ед. -т    3 мн. -ни
```

Прошедшее:

```
ед. -л
мн. -ли
```

Будущее:

ЛИЧНАЯ ФОРМА `БУДТИ` + ИНФИНИТИВ ОСНОВНОГО ГЛАГОЛА.

```
будем, будеш, будет,
будеми, будете, будени
```

Условное:

```
би + прошедшее
```

Пассив:

```
се + глагол
```

## Синтаксис

```
SVO
```

Причастия:

```
кторий + глагол
```

## Число

Только:

```
единственное
множественное
```

**Двойственное число отсутствует.**
